Module 10: Circuit Breaker (The Safety Fuse)

🏠 The Electrical Fuse Analogy

Imagine your house has a fuse box.

  • If one appliance (Toaster) malfunctions and draws too much power, the Fuse Blows (Circuit Opens).
  • This cuts off power to the Toaster immediately.
  • Why? To prevent the whole house from burning down ("Cascading Failure").

In System Design, we do the same. If a Service is failing, we "Cut the Line" to save the rest of the system.

1. The Problem: Cascading Failure

Service A calls Service B. Service B is slow/down.

Result: Service A waits forever. Threads pile up. Service A crashes. All users suffer.

2. The Solution: Three States

The Circuit Breaker is a State Machine that monitors failures.

  1. CLOSED (🟢 Normal): Checks flows freely.
    If failures < 50%, stay here.

  2. OPEN (🔴 Broken): The Fuse has blown.
    All calls fail immediately (Fast Fallback). We don't even try to call the bad service.
    Wait for X seconds (Cool down period).

  3. HALF-OPEN (🟡 Testing): After the wait time.
    Allow a few "Test Calls".
    If Success -> Go back to CLOSED (🟢).
    If Fail -> Go back to OPEN (🔴).

3. Important Configuration Settings

How does the Circuit know when to open? We configure it with numbers.

Setting Value Meaning
Sliding Window Count-based (5) "Look at the last 5 calls."
Failure Threshold 50% "If 3 out of 5 fail, Trip the Circuit."
Wait Duration 10000ms (10s) "How long to stay OPEN before testing (Half-Open)."

4. Circuit Breaker vs. Retry

🔄 Retry vs. ⚡ Circuit Breaker

Retry: "It failed? Try again immediately!" (Good for momentary blips).

Circuit Breaker: "It failed 5 times? Stop trying! Let it recover." (Good for persistent outages).

Using them together is powerful, but dangerous if not tuned correctly.

4. How it Runs in Code

We use the @CircuitBreaker annotation.

@CircuitBreaker(name = "payment", fallbackMethod = "fallback")
public String pay() {
   // Call External Service
}

public String fallback(Exception e) {
   return "System Busy, try later";
}

If the circuit is OPEN, Java executes the fallback method instantly.
