Module 15: Bulkhead Pattern (Isolation)

1. The Problem: Resource Exhaustion

In a Servlet container (like Tomcat), there is a limited pool of worker threads (e.g., 200).

If Service A becomes slow (takes 5s to respond) and receives high traffic, it will hog all 200 threads waiting for responses.

Result: Service B, which is healthy, becomes unreachable because there are no threads left to handle the requests! This is a Cascading Failure.

2. The Solution: Bulkheads

🚢 The Ship Analogy

Ships are divided into watertight compartments called Bulkheads.

  • If the hull is breached in Section 1, water fills only Section 1.
  • The other sections remain dry, and the ship stays afloat.
  • Without bulkheads, water would flow everywhere, and the ship would sink (like the Titanic).
