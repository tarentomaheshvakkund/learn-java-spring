Module 16: Distributed Tracing

1. The Problem: "Needle in a Haystack"

In a system with millions of logs, how do you find all logs related to ONE specific user request?

If an error happens in the Database Service, how do you know which User Request caused it?

2. The Solution: Correlation IDs

📦 The Package Tracking Analogy

When you buy something from Amazon, you get a Tracking Number (e.g., 1Z999...).

  • Warehouse scans it: "Picked up" (ID: 1Z999)
  • carrier scans it: "In Transit" (ID: 1Z999)
  • Driver scans it: "Delivered" (ID: 1Z999)

Even though different people handled it, you can see the entire history using that one ID.

3. Key Concepts

Trace ID

The "Tracking Number".

One unique ID for the entire lifecycle of the request, across all microservices.

Span ID

The "Step ID".

A unique ID for a specific operation (e.g., "Service A calling Service B").
