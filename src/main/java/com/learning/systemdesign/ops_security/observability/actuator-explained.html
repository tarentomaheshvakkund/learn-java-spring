Module 8: Observability (The Dashboard)

🚗 The Car Dashboard Analogy

Imagine driving a car without a dashboard.

  • You don't know how fast you are going (**Metrics**).
  • You don't know if you have fuel (**Health**).
  • You don't know if the engine is broken (**Loggers**).

Spring Boot Actuator is your application's Dashboard.

1. What is Observability?

When we deploy code to a server (Production), we can't see the code running. We need "Windows" into the application to see if it is healthy.

This is called Observability.

2. The Three Key Indicators

Actuator gives us 3 main URLs (Endpoints) to check the system:

  1. /actuator/health: "Are you alive?"
    Example: Kubernetes checks this. If it says "DOWN", it restarts the app.

  2. /actuator/metrics: "How are you performing?"
    Example: CPU Usage, Free Memory, Number of API calls per second.

  3. /actuator/info: "Who are you?"
    Example: Version 1.2.0, Git Commit Hash.
