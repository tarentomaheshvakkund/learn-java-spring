✨ Java 21: String Templates PREVIEW

📈 Evolution of String Formatting

❌ Concatenation

Messy with many variables

"Hello, " + name + "!"

⚠️ String.format()

Better but verbose

String.format("Hello, %s!", name)

✅ String Templates

Clean and expressive!

STR."Hello, \{name}!"

🔧 The STR Processor

String Templates use a template processor to interpolate values. STR is the built-in processor for simple string interpolation.

STR
.
"
Hello,
\{name}
!
"

STR = Template Processor  |  \{...} = Expression to embed

Basic Usage

String name = "Alice";
int age = 25;
double balance = 1234.56;

// Simple interpolation
String greeting = STR."Hello, \{name}!";

// Multiple values
String info = STR."\{name} is \{age} years old. Balance: $\{balance}";

// Expressions work too!
String future = STR."Next year you'll be \{age + 1}";

⚖️ Side-by-Side Comparison

❌ Concatenation
String msg = "User " + name + " (age " + age + ") has " + "balance: $" + balance;

😵 Hard to read
🐛 Easy to miss quotes/spaces
❌ Gets worse with more variables

⚠️ String.format()
String msg = String.format( "User %s (age %d) has " + "balance: $%.2f", name, age, balance);

📝 Format specifiers to remember
🔢 Must match order of args
⚠️ Runtime errors if wrong

✅ String Template
String msg = STR."User \{name} " + "(age \{age}) has " + "balance: $\{balance}";

✨ Clear and readable
🎯 Values inline where used
✅ Compile-time safety

📄 Multi-line Templates

Combine String Templates with Text Blocks for beautiful multi-line strings!

📝 Template Code

String name = "Mahesh";
int age = 30;

String json = STR."""
    {
        "name": "\{name}",
        "age": \{age},
        "adult": \{age >= 18},
        "category": "\{age < 30 ? "young" : "experienced"}"
    }
    """;

📤 Output

{
    "name": "Mahesh",
    "age": 30,
    "adult": true,
    "category": "experienced"
}

⚠️ Preview Feature Notice

🔬 This is a Preview Feature (JEP 430)

String Templates are a preview feature in Java 21. The syntax and behavior may change in future releases before becoming a permanent feature.

Note: As of Java 23, String Templates were withdrawn for redesign. Check the latest Java documentation for current status.

🚀 Running with Preview Features

# Compile
javac --enable-preview --source 21 YourFile.java

# Run
java --enable-preview YourFile

🎯 Why String Templates?

📖

Readable

Values appear exactly where they're used in the string. No more counting arguments!

🔒

Type Safe

Compiler validates expressions at compile time. No runtime format errors!

🧮

Expressions

Embed any Java expression: method calls, arithmetic, ternary operators!

🔌

Extensible

Custom processors can add validation, SQL injection prevention, and more!
