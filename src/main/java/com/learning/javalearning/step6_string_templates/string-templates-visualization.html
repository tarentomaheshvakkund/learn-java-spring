📝 String Templates

Safe, Expression Interpolation

Java 21 (Preview) --enable-preview Required

🎯 What are String Templates?

String Templates allow you to embed expressions directly in strings with compile-time safety!

// Old way: String concatenation String name = "Alice"; int age = 30; String msg = "Hello, " + name + "! You are " + age + " years old."; // Old way: String.format (runtime) String msg = String.format("Hello, %s! You are %d years old.", name, age); // New way: String Templates (compile-time checked!) String msg = STR."Hello, \{name}! You are \{age} years old."; // ↑ ↑ ↑ // Template processor Embedded expressions
⚠️ Preview Feature: Requires --enable-preview flag to compile and run!

🔧 STR Template Processor

STR is the standard template processor for simple interpolation.

// Basic interpolation String name = "World"; String greeting = STR."Hello, \{name}!"; // Output: "Hello, World!" // Expressions in templates int x = 10, y = 20; String result = STR."\{x} + \{y} = \{x + y}"; // Output: "10 + 20 = 30" // Method calls String text = "java"; String upper = STR."Uppercase: \{text.toUpperCase()}"; // Output: "Uppercase: JAVA" // Complex expressions List names = List.of("Alice", "Bob"); String list = STR."Names: \{names.stream().collect(Collectors.joining(", "))}"; // Output: "Names: Alice, Bob"

🛡️ FMT Template Processor

FMT adds formatting capabilities like printf.

// Format numbers double pi = Math.PI; String formatted = FMT."Pi = %.2f\{pi}"; // Output: "Pi = 3.14" // Multiple formats int count = 42; double price = 19.99; String msg = FMT.""" Items: %d\{count} Total: $%.2f\{price * count} """; // Output: // Items: 42 // Total: $839.58

🎨 Multi-line Templates

Combine with text blocks formulti-line content!

String name = "Alice"; int age = 30; String city = "NYC"; String json = STR.""" { "name": "\{name}", "age": \{age}, "city": "\{city}" } """; // SQL with parameters String table = "users"; int minAge = 18; String sql = STR.""" SELECT * FROM \{table} WHERE age >= \{minAge} ORDER BY name """;
