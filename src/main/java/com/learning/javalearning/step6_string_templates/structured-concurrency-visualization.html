🤔 The Problem with Traditional Concurrency

With `ExecutorService`, if one task fails, others keep running wastefully!

❌ Traditional ExecutorService
💥
fetchUser()
FAILED
⏳
fetchOrders()
STILL RUNNING!
⏳
fetchReco()
WASTING CPU!
😱 User fails, but others keep running pointlessly!

✨ Structured Concurrency Solution

Tasks are treated as a single unit. If one fails, ALL are cancelled!

✅ StructuredTaskScope.ShutdownOnFailure
💥
fetchUser()
FAILED
🚫
fetchOrders()
CANCELLED
🚫
fetchReco()
CANCELLED
✅ User fails → Others cancelled immediately. No waste!

🎯 Two Shutdown Strategies

🛡️ ShutdownOnFailure
Use Case: Need ALL results to proceed
✅ ALL succeed → Return all results
❌ ANY fails → Cancel ALL, throw exception
Example: Building a user dashboard that needs user info, orders, AND recommendations
⚡ ShutdownOnSuccess
Use Case: Need FIRST successful result
✅ ANY succeeds → Return it, cancel others
❌ ALL fail → Throw exception
Example: Query cache + database, use whichever responds first

💻 Code Example

ShutdownOnFailure - All or Nothing

try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    // Fork concurrent tasks
    Subtask<User> userTask = scope.fork(() -> fetchUser());
    Subtask<Orders> ordersTask = scope.fork(() -> fetchOrders());
    Subtask<Reco> recoTask = scope.fork(() -> fetchReco());

    scope.join();           // Wait for all tasks
    scope.throwIfFailed();  // Throw if any failed

    // All succeeded! Build response
    return new Dashboard(
        userTask.get(),
        ordersTask.get(),
        recoTask.get()
    );
} // Scope auto-closes, no cleanup needed!

🔑 Scoped Values: Modern ThreadLocal

Immutable, inheritable, auto-cleanup context sharing for virtual threads.

Feature ThreadLocal ScopedValue
Mutability Mutable ❌ Immutable ✅
Cleanup Manual remove() ❌ Automatic ✅
Memory Leaks Common problem ❌ Not possible ✅
Virtual Threads Poor performance ❌ Optimized ✅
Child Threads Not inherited ❌ Inherited ✅

ScopedValue Usage

static final ScopedValue<String> CURRENT_USER = ScopedValue.newInstance();

// Bind value for a scope
ScopedValue.where(CURRENT_USER, "alice")
    .run(() -> {
        // Value accessible everywhere in this scope!
        String user = CURRENT_USER.get();  // "alice"
        
        // Child virtual threads INHERIT the value!
        try (var scope = new ShutdownOnFailure()) {
            scope.fork(() -> {
                CURRENT_USER.get();  // Still "alice"! ✅
            });
        }
    });

// Outside scope: CURRENT_USER.get() throws NoSuchElementException

🎓 Key Takeaways

  • ✅ Structured Concurrency = Tasks as a unit (all-or-nothing)
  • ✅ ShutdownOnFailure = Need all results, fail fast
  • ✅ ShutdownOnSuccess = Race for first result
  • ✅ Scoped Values = Better ThreadLocal for virtual threads
