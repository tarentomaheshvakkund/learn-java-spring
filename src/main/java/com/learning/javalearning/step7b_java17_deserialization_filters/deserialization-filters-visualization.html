⚠️ The Deserialization Problem

Security Risk: Malicious data can exploit Java deserialization to execute arbitrary code!
// Vulnerable code (NO FILTER!) ObjectInputStream ois = new ObjectInputStream(input); Object obj = ois.readObject(); // DANGEROUS! // Attacker sends: // - Gadget chains (execute code) // - Denial of service attacks // - Consume excessive memory/CPU

✅ Basic Filter

// Allow only specific classes ObjectInputFilter filter = ObjectInputFilter.Config .createFilter("com.example.User;!*"); // Pattern syntax: // "com.example.User" - Allow this class // "com.example.*" - Allow this package // "!*" - Reject everything else ObjectInputStream ois = new ObjectInputStream(input); ois.setObjectInputFilter(filter); Object obj = ois.readObject(); // Safe!

🛡️ Custom Filter

ObjectInputFilter customFilter = filterInfo -> { Class serialClass = filterInfo.serialClass(); // Reject if class is null (array, primitive, etc.) if (serialClass == null) { return ObjectInputFilter.Status.UNDECIDED; } // Only allow specific classes if (serialClass == User.class || serialClass == Order.class) { return ObjectInputFilter.Status.ALLOWED; } // Reject everything else return ObjectInputFilter.Status.REJECTED; }; ois.setObjectInputFilter(customFilter);

📊 Filter Info

ObjectInputFilter filter = filterInfo -> { // Check class Class clazz = filterInfo.serialClass(); // Check array depth long depth = filterInfo.depth(); if (depth > 10) { return ObjectInputFilter.Status.REJECTED; } // Check object count long count = filterInfo.references(); if (count > 1000) { return ObjectInputFilter.Status.REJECTED; } // Check bytes read long bytes = filterInfo.streamBytes(); if (bytes > 1_000_000) { // 1 MB limit return ObjectInputFilter.Status.REJECTED; } // Check array length long arrayLength = filterInfo.arrayLength(); if (arrayLength > 10000) { return ObjectInputFilter.Status.REJECTED; } return ObjectInputFilter.Status.UNDECIDED; };

🌍 JVM-Wide Filter

// Set global filter for entire JVM ObjectInputFilter globalFilter = ObjectInputFilter.Config .createFilter("com.example.*;!*"); ObjectInputFilter.Config .setSerialFilter(globalFilter); // Or via system property: // -Djdk.serialFilter="com.example.*;!*" // Or via security properties file: // jdk.serialFilter=com.example.*;!*

💼 Real-World Example

class SafeDeserializer { private static final Set> ALLOWED = Set.of( User.class, Order.class, Product.class, String.class, Integer.class, Long.class, Date.class, ArrayList.class, HashMap.class ); public static Object deserialize(byte[] data) throws IOException, ClassNotFoundException { ObjectInputFilter filter = filterInfo -> { Class clazz = filterInfo.serialClass(); if (clazz == null) { return ObjectInputFilter.Status.UNDECIDED; } // Limits if (filterInfo.depth() > 20 || filterInfo.references() > 10000 || filterInfo.streamBytes() > 10_000_000) { return ObjectInputFilter.Status.REJECTED; } // Allowlist check if (ALLOWED.contains(clazz) || ALLOWED.stream().anyMatch( allowed -> clazz.getName() .startsWith(allowed.getPackageName()))) { return ObjectInputFilter.Status.ALLOWED; } // Reject unknown classes log.warn("Rejected class: " + clazz.getName()); return ObjectInputFilter.Status.REJECTED; }; try (ByteArrayInputStream bis = new ByteArrayInputStream(data); ObjectInputStream ois = new ObjectInputStream(bis)) { ois.setObjectInputFilter(filter); return ois.readObject(); } } }
