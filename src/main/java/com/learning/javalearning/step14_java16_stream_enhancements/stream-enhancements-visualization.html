📋 Stream.toList()

Finally! A simple way to collect streams to lists!

❌ Before Java 16

// Verbose! List names = users.stream() .map(User::getName) .collect(Collectors.toList()); // Too many imports import java.util.stream.Collectors; // Long method chain .collect(Collectors.toList())

✅ Java 16+

// Simple! List names = users.stream() .map(User::getName) .toList(); // No extra imports // Short and clear .toList()
⚠️ Note: toList() returns an unmodifiable list! Use collect(Collectors.toList()) if you need mutable.

🔒 Immutability

// toList() returns unmodifiable list List names = users.stream() .map(User::getName) .toList(); names.add("New"); // ❌ UnsupportedOperationException! // If you need mutable list: List mutable = users.stream() .map(User::getName) .collect(Collectors.toCollection(ArrayList::new)); mutable.add("New"); // ✅ Works! // Most of the time, immutable is better: // - Thread-safe // - Prevents accidental modification // - Better performance // - Cleaner API

🎯 Common Use Cases

// Filter and collect List evens = numbers.stream() .filter(n -> n % 2 == 0) .toList(); // Map and collect List upperNames = names.stream() .map(String::toUpperCase) .toList(); // FlatMap and collect List allWords = sentences.stream() .flatMap(s -> Arrays.stream(s.split(" "))) .toList(); // Sorted and collect List sortedUsers = users.stream() .sorted(Comparator.comparing(User::getName)) .toList(); // Distinct and collect List uniqueNames = names.stream() .distinct() .toList(); // Limit and collect List topTen = users.stream() .limit(10) .toList();

🔀 Teeing Collector

Process stream with two collectors simultaneously!

// Calculate average AND count in ONE pass record Statistics(double average, long count) {} Statistics stats = numbers.stream() .collect(Collectors.teeing( Collectors.averagingInt(n -> n), // Collector 1 Collectors.counting(), // Collector 2 (avg, count) -> new Statistics(avg, count) // Merger )); System.out.println("Average: " + stats.average()); System.out.println("Count: " + stats.count()); // Without teeing (TWO passes - inefficient!) double avg = numbers.stream().mapToInt(n -> n).average().orElse(0); long count = numbers.stream().count(); // Stream processed twice!

📊 Multiple Aggregations

record MinMax(int min, int max) {} // Get min AND max in single pass MinMax minMax = numbers.stream() .collect(Collectors.teeing( Collectors.minBy(Integer::compare), Collectors.maxBy(Integer::compare), (min, max) -> new MinMax( min.orElse(0), max.orElse(0) ) )); // Separate lists of adults and minors record Categorized( List adults, List minors ) {} Categorized result = people.stream() .collect(Collectors.teeing( Collectors.filtering( p -> p.age() >= 18, Collectors.toList() ), Collectors.filtering( p -> p.age() < 18, Collectors.toList() ), (adults, minors) -> new Categorized(adults, minors) ));

💼 Real-World: Sales Report

record SalesReport( double totalRevenue, long numberOfSales, double averageOrderValue, Optional largestOrder ) {} SalesReport generateReport(List orders) { return orders.stream() .collect(Collectors.teeing( // First aggregation: sum and count Collectors.teeing( Collectors.summingDouble(Order::getAmount), Collectors.counting(), (sum, count) -> Map.entry(sum, count) ), // Second aggregation: max order Collectors.maxBy( Comparator.comparing(Order::getAmount) ), // Combine results (sumAndCount, maxOrder) -> new SalesReport( sumAndCount.getKey(), // total sumAndCount.getValue(), // count sumAndCount.getKey() / sumAndCount.getValue(), // average maxOrder // largest ) )); } // Single stream pass for complete report!

📈 Performance Benefits

// ❌ Multiple passes (SLOW!) List list = transactions.stream() .filter(t -> t.amount() > 100) .collect(Collectors.toList()); double sum = list.stream() .mapToDouble(Transaction::amount) .sum(); double avg = list.stream() .mapToDouble(Transaction::amount) .average() .orElse(0); long count = list.size(); // ✅ Single pass with teeing (FAST!) record Summary(double sum, double avg, long count) {} Summary summary = transactions.stream() .filter(t -> t.amount() > 100) .map(Transaction::amount) .collect(Collectors.teeing( Collectors.summingDouble(d -> d), Collectors.teeing( Collectors.averagingDouble(d -> d), Collectors.counting(), (avg, count) -> Map.entry(avg, count) ), (sum, avgAndCount) -> new Summary( sum, avgAndCount.getKey(), avgAndCount.getValue() ) ));
