Java 12-16: toList(), Teeing Collector & More

📊 Old Way vs New Way

Java 11 & Earlier
collect(Collectors.toList())
List<String> result = stream .filter(...) .map(...) .collect(Collectors.toList());
Characteristics:
  • ✅ Mutable list
  • ❌ Verbose syntax
  • ⚠️ Slower performance
  • ⚠️ Allows null elements
Java 16+
toList()
List<String> result = stream .filter(...) .map(...) .toList();
Characteristics:
  • 🔒 Immutable list
  • ✅ Concise syntax
  • ⚡ Better performance
  • ✅ Null-safe by default

💼 Real-World Use Cases

📱 API Response Processing
Scenario: Return immutable list from REST API
Solution: Use toList() for safe, immutable responses
return users.stream() .filter(User::isActive) .map(User::getName) .toList(); // Safe for API response
📊 Statistical Analysis
Scenario: Calculate min, max, and average in one pass
Solution: Use Collectors.teeing() for efficiency
var stats = scores.stream().collect( Collectors.teeing( Collectors.summarizingDouble(Double::doubleValue), Collectors.counting(), (summary, count) -> new Stats(summary, count) ) );
🏢 Business Intelligence
Scenario: Group sales by region and calculate totals
Solution: Combine toList() with teeing()
var report = sales.stream().collect( Collectors.teeing( Collectors.summingDouble(Sale::amount), Collectors.groupingBy(Sale::region), (total, byRegion) -> new SalesReport(total, byRegion) ) );
🎮 Dynamic List Building
Scenario: Build list that needs modification after creation
Solution: Use collect(Collectors.toList()) or wrap toList()
// Option 1: Old way (mutable) List<Item> items = stream.collect(Collectors.toList()); items.add(defaultItem); // Option 2: New way (convert to mutable) List<Item> items = new ArrayList<>(stream.toList()); items.add(defaultItem);

Step-by-Step Migration Strategy

Step 3: Replace Gradually
