📚 Sequenced Collections

Java 21's Unified Interface for First/Last Access

😰 The Problem Before Java 21

❌ Inconsistent Chaos!

Want to get the first or last element? Every collection type had its own special way! You had to remember different methods for each collection. 🤯

Collection Type Get First Element Get Last Element
List list.get(0) list.get(list.size() - 1) MESSY!
Deque deque.getFirst() deque.getLast()
SortedSet set.first() set.last()
LinkedHashSet set.iterator().next() UGLY! // No direct way! 😱

🏪 The Remote Control Analogy

Imagine if every TV brand had different button layouts: Samsung uses "CH+" for volume, LG uses "VOL↑", Sony uses "V+". That's what Java collections were like! Every collection "brand" had its own way to do the same thing. 🎮

🎉 The Solution: Sequenced Collections!

✅ Java 21: One Unified Interface!

Now ALL collections that have a defined order implement the same interface with consistent method names! No more memorizing different APIs! 🚀

New Interface Hierarchy

SequencedCollection<E>
(The base interface for ordered collections)
SequencedSet<E>
extends SequencedCollection
Implementations:
LinkedHashSet, TreeSet
SequencedMap<K,V>
separate hierarchy for maps
Implementations:
LinkedHashMap, TreeMap

Note: List and Deque already extend SequencedCollection in Java 21!

🛠️ New Unified Methods

👉 Access First

getFirst()

Returns the first element in the sequence

👈 Access Last

getLast()

Returns the last element in the sequence

➕ Add First

addFirst(E element)

Inserts element at the beginning

➕ Add Last

addLast(E element)

Appends element at the end

🗑️ Remove First

removeFirst()

Removes and returns first element

🗑️ Remove Last

removeLast()

Removes and returns last element

🔄 Reversed View

reversed()

Returns a reversed view of the collection. Zero-copy! Changes to original reflect in reversed view and vice versa! 🚀

📊 Before vs After Comparison

❌ Before Java 21

List<String> names = new ArrayList<>(); // Getting first - OK String first = names.get(0); // Getting last - MESSY! 😱 String last = names.get( names.size() - 1 ); // Adding at start - No direct way! names.add(0, "First"); // Iterating in reverse - Complex! for (int i = names.size()-1; i >= 0; i--) { System.out.println(names.get(i)); }

✅ Java 21

List<String> names = new ArrayList<>(); // Getting first - CLEAN! ✨ String first = names.getFirst(); // Getting last - CLEAN! ✨ String last = names.getLast(); // Adding at start - EASY! 🎯 names.addFirst("First"); // Iterating in reverse - TRIVIAL! 🚀 for (String name : names.reversed()) { System.out.println(name); }

🪄 The Magic of reversed(): Zero-Copy Views!

🔍 The Mirror Analogy

reversed() is like placing a mirror in front of your collection. You see everything backwards, but it's NOT a copy! When you change something in the "mirror", the original changes too (and vice versa). It's the SAME data, just viewed differently! 🪞

⚡ ZERO COPY! Same memory, different view!

💡 Key Point: Live View!

List<Integer> nums = new ArrayList<>(List.of(1, 2, 3)); List<Integer> rev = nums.reversed(); // Modify original nums.addLast(4); // Reversed view automatically updates! System.out.println(rev); // [4, 3, 2, 1] ✨ // Modify reversed view rev.addFirst(5); // Original also updates! System.out.println(nums); // [1, 2, 3, 4, 5] 🤯

🗺️ SequencedMap: Same Benefits for Maps!

❌ Before Java 21

LinkedHashMap<String, Integer> map = new LinkedHashMap<>(); // Getting first entry - UGLY! 😱 Map.Entry<String, Integer> first = map.entrySet().iterator().next(); // Getting last entry - NO WAY! 😰 // You'd have to iterate through everything! // Iterating in reverse - NIGHTMARE! 💀 List<String> keys = new ArrayList<>(map.keySet()); Collections.reverse(keys); for (String key : keys) { ... }

✅ Java 21

LinkedHashMap<String, Integer> map = new LinkedHashMap<>(); // Getting first entry - CLEAN! ✨ Map.Entry<String, Integer> first = map.firstEntry(); // Getting last entry - CLEAN! ✨ Map.Entry<String, Integer> last = map.lastEntry(); // Iterating in reverse - EASY! 🚀 for (Map.Entry<String, Integer> e : map.reversed().entrySet()) { ... }

🔑 firstEntry()

Returns first key-value pair

🔑 lastEntry()

Returns last key-value pair

➕ putFirst(K, V)

Inserts entry at beginning

➕ putLast(K, V)

Appends entry at end

🗑️ pollFirstEntry()

Removes and returns first entry

🗑️ pollLastEntry()

Removes and returns last entry

💼 Real-World Example: Message Queue

// Processing messages in a queue Deque<Message> messageQueue = new ArrayDeque<>(); // Add new message (arrives at end) messageQueue.addLast(new Message("Hello")); // Add urgent message (jump to front!) messageQueue.addFirst(new Message("URGENT!")); // Process messages (from front) while (!messageQueue.isEmpty()) { Message msg = messageQueue.removeFirst(); process(msg); } // Check what's coming up next Message next = messageQueue.getFirst(); // Peek without removing // Review messages in reverse (newest to oldest) for (Message msg : messageQueue.reversed()) { System.out.println(msg); }

🎯 Use Case: Perfect for message queues, undo/redo stacks, browsing history, recent items lists, and any scenario where order matters and you need quick access to both ends!
