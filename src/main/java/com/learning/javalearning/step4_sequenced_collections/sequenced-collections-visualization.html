🔗 Sequenced Collections

Encounter Order with First-Last Access

Java 21 (Standard)

📚 What are Sequenced Collections?

A new collection hierarchy that adds explicit support for collections with a definedencounter order, providing uniform access to first and last elements.

// New interfaces in Java 21: interface SequencedCollection<E> extends Collection<E> interface SequencedSet<E> extends SequencedCollection<E>, Set<E> interface SequencedMap<K,V> extends Map<K,V> // Key methods: void addFirst(E); void addLast(E); E getFirst(); E getLast(); E removeFirst(); E removeLast(); SequencedCollection<E> reversed();

✨ Why Sequenced Collections?

  • Uniform API for collections with order
  • First/last access without workarounds
  • Bidirectional iteration made easy
  • Fixes inconsistencies in Collection APIs

❌ The Problem Before Java 21

Accessing first/last elements was inconsistent across collections!

// Before Java 21: Inconsistent APIs // List: get(0) and get(size()-1) List<String> list = new ArrayList<>(); String first = list.get(0); // Index-based String last = list.get(list.size() - 1); // Verbose // Deque: getFirst() and getLast() Deque<String> deque = new LinkedList<>(); String first = deque.getFirst(); // Different method! String last = deque.getLast(); // Set: No direct way! Set<String> set = new LinkedHashSet<>(); String first = set.iterator().next(); // Awkward String last = ??? // No easy way! // Map: No direct way for first/last entry! Map<String, Integer> map = new LinkedHashMap<>(); var first = map.entrySet().iterator().next(); // Clunky
Problem: Different collections, different methods, no consistency!

✅ The Solution: Uniform API

Java 21 introduces consistent methods across all sequenced collections!

// Java 21: Consistent API everywhere! List<String> list = List.of("A", "B", "C"); list.getFirst(); // "A" list.getLast(); // "C" Deque<String> deque = new ArrayDeque<>(list); deque.getFirst(); // "A" - Same method! deque.getLast(); // "C" - Same method! Set<String> set = new LinkedHashSet<>(list); set.getFirst(); // "A" - Same method! set.getLast(); // "C" - Same method! // Even SortedSet works! SortedSet<String> sorted = new TreeSet<>(list); sorted.getFirst(); // "A" (smallest) sorted.getLast(); // "C" (largest)

✨ Benefits

  • ✅ One method name for all collections
  • ✅ Generic code works with any SequencedCollection
  • ✅ No need to remember different APIs
  • ✅ More readable and maintainable

➕ Adding Elements: First & Last

Add elements to either end with addFirst() and addLast().

List<String> list = new ArrayList<>(); // Traditional way list.add(0, "First"); // Add at beginning list.add("Last"); // Add at end // Java 21: Explicit and clear list.addFirst("First"); // Clearer intent! list.addLast("Last"); // Explicit! // Works with all sequenced collections Deque<String> deque = new ArrayDeque<>(); deque.addFirst("A"); // [A] deque.addLast("B"); // [A, B] deque.addFirst("Z"); // [Z, A, B] deque.addLast("C"); // [Z, A, B, C] // LinkedHashSet (maintains insertion order) SequencedSet<Integer> set = new LinkedHashSet<>(); set.addFirst(10); // {10} set.addFirst(20); // {20, 10} set.addLast(30); // {20, 10, 30}

➖ Removing Elements: First & Last

Remove and return first/last elements consistently.

List<String> list = new ArrayList<>( List.of("A", "B", "C", "D") ); // Remove from both ends String first = list.removeFirst(); // "A" String last = list.removeLast(); // "D" // list is now ["B", "C"] // Works like a queue Deque<String> queue = new ArrayDeque<>(); queue.addLast("Task1"); queue.addLast("Task2"); queue.addLast("Task3"); // Process in order while (!queue.isEmpty()) { String task = queue.removeFirst(); System.out.println("Processing: " + task); } // Works like a stack Deque<String> stack = new ArrayDeque<>(); stack.addFirst("Page1"); stack.addFirst("Page2"); stack.addFirst("Page3"); // Pop in LIFO order while (!stack.isEmpty()) { String page = stack.removeFirst(); System.out.println("Back to: " + page); }

🔄 Reversed View

Get a reversed view of any sequenced collection - no copying!

List<String> original = List.of("A", "B", "C", "D"); // Get reversed view (not a copy!) SequencedCollection<String> reversed = original.reversed(); System.out.println(original); // [A, B, C, D] System.out.println(reversed); // [D, C, B, A] // reversed() is a VIEW - changes reflect back! List<String> mutable = new ArrayList<>(original); List<String> reversedView = mutable.reversed(); reversedView.addFirst("Z"); // Add "Z" at "start" of reversed System.out.println(mutable); // [A, B, C, D, Z] System.out.println(reversedView); // [Z, D, C, B, A] // Iterate in reverse easily! List<Integer> numbers = List.of(1, 2, 3, 4, 5); for (Integer num : numbers.reversed()) { System.out.println(num); // 5, 4, 3, 2, 1 } // No need for manual reversal loops!

✨ Reversed View Benefits

  • ✅ No copying - O(1) time & space
  • ✅ Bidirectional changes
  • ✅ Clean reverse iteration
  • ✅ Works with all sequenced collections

🗺️ SequencedMap

Maps with defined entry order get first/last entry access!

// LinkedHashMap now implements SequencedMap! SequencedMap<String, Integer> map = new LinkedHashMap<>(); map.put("first", 1); map.put("second", 2); map.put("third", 3); // Access first entry Map.Entry<String, Integer> first = map.firstEntry(); System.out.println(first); // first=1 // Access last entry Map.Entry<String, Integer> last = map.lastEntry(); System.out.println(last); // third=3 // Add at beginning map.putFirst("zero", 0); // map: {zero=0, first=1, second=2, third=3} // Add at end map.putLast("fourth", 4); // map: {zero=0, first=1, second=2, third=3, fourth=4} // Remove from ends map.pollFirstEntry(); // Removes zero=0 map.pollLastEntry(); // Removes fourth=4 // Reversed view of map! SequencedMap<String, Integer> reversed = map.reversed(); for (var entry : reversed.entrySet()) { System.out.println(entry); // Iterates in reverse order! }

💼 Practical Example: LRU Cache

Implement an LRU (Least Recently Used) cache easily!

class LRUCache<K, V> { private final int maxSize; private final SequencedMap<K, V> cache; public LRUCache(int maxSize) { this.maxSize = maxSize; this.cache = new LinkedHashMap<>(); } public V get(K key) { V value = cache.remove(key); if (value != null) { // Move to end (most recently used) cache.putLast(key, value); } return value; } public void put(K key, V value) { // Remove if exists cache.remove(key); // Add to end (most recently used) cache.putLast(key, value); // Evict oldest if over capacity if (cache.size() > maxSize) { // Remove least recently used (first entry) cache.pollFirstEntry(); } } public V getLeastRecentlyUsed() { return cache.firstEntry().getValue(); } public V getMostRecentlyUsed() { return cache.lastEntry().getValue(); } } // Usage: LRUCache<String, String> cache = new LRUCache<>(3); cache.put("A", "Data A"); cache.put("B", "Data B"); cache.put("C", "Data C"); cache.put("D", "Data D"); // Evicts "A" System.out.println(cache.get("B")); // Data B // B moves to end, C is now LRU
