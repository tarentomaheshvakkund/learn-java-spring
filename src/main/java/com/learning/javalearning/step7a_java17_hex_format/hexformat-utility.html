🤔 What is HexFormat?

🔢 Real Life: Binary Translator

Imagine you have a secret code written in binary (0s and 1s), but it's too long to read:
Binary: 11001010 11111110 10111010 10111110

Old Way (Before Java 17):
• Write your own converter
• Or use external libraries (Apache Commons Codec)
• Handle uppercase/lowercase manually
• Format delimiters yourself
• Lots of boilerplate code! 😰

New Way (Java 17 HexFormat):
• One-line conversion! ✨
• Built into Java (no external libraries!)
• Automatic formatting options
• Clean and simple API

This is HexFormat! Convert bytes to hex strings (and back) effortlessly! 🎉

💡 What is Hexadecimal?

Hexadecimal (Hex) is a number system that uses 16 symbols: 0-9 and A-F

Why use hex?
• Compact way to represent binary data
• Easier to read than long binary strings
• Each hex digit = 4 binary bits
• Common in networking, cryptography, colors

Example:
Binary: 11001010 → Hex: CA (much shorter!)

Bytes ↔️ Hex Conversion

📦 Bytes

0xCA 0xFE 0xBA 0xBE

Binary data (hard to read!)

↔️

🔢 Hex String

"CAFEBABE"

Human-readable!

HexFormat makes this conversion super easy!

🚀 Basic Usage

📝 Simple Examples

import java.util.HexFormat; // Create a basic HexFormat HexFormat hex = HexFormat.of(); // Example 1: Bytes to Hex String 📦 → 🔢 byte[] bytes = {(byte) 0xCA, (byte) 0xFE, (byte) 0xBA, (byte) 0xBE}; String hexStr = hex.formatHex(bytes); System.out.println(hexStr); // Output: "cafebabe" // Example 2: Hex String to Bytes 🔢 → 📦 byte[] parsed = hex.parseHex("cafebabe"); // parsed = {0xCA, 0xFE, 0xBA, 0xBE} // Example 3: Single byte to hex String singleByte = hex.toHexDigits((byte) 255); System.out.println(singleByte); // Output: "ff" // Example 4: Int to hex String intHex = hex.toHexDigits(42); System.out.println(intHex); // Output: "0000002a"

✅ Key Methods

formatHex(byte[]) → Convert bytes to hex string
parseHex(String) → Convert hex string to bytes
toHexDigits(byte) → Convert single byte to hex
toHexDigits(int) → Convert int to hex (8 chars)
toHexDigits(long) → Convert long to hex (16 chars)

🎨 Formatting Options

🎨 Real Life: Name Tags

Think of hex formatting like designing name tags:

Basic tag: "cafebabe"
Uppercase: "CAFEBABE" (more formal!)
With separators: "CA:FE:BA:BE" (easier to read!)
With labels: "[CA] [FE] [BA] [BE]" (extra fancy!)

1️⃣ Uppercase

Convert to uppercase letters

HexFormat hex = HexFormat.of() .withUpperCase(); byte[] bytes = {(byte) 0xCA, (byte) 0xFE}; String result = hex.formatHex(bytes); // Output: "CAFE"

2️⃣ With Delimiter

Add separator between bytes

HexFormat hex = HexFormat .ofDelimiter(":"); byte[] bytes = {(byte) 0xCA, (byte) 0xFE}; String result = hex.formatHex(bytes); // Output: "ca:fe"

3️⃣ With Prefix

Add prefix before each byte

HexFormat hex = HexFormat.of() .withPrefix("0x"); byte[] bytes = {(byte) 0xCA, (byte) 0xFE}; String result = hex.formatHex(bytes); // Output: "0xca0xfe"

4️⃣ With Suffix

Add suffix after each byte

HexFormat hex = HexFormat.of() .withSuffix("h"); byte[] bytes = {(byte) 0xCA, (byte) 0xFE}; String result = hex.formatHex(bytes); // Output: "cahfeh"

🎨 Combined Formatting

You can combine multiple formatting options!

// Example 1: Uppercase with delimiter HexFormat hex1 = HexFormat.ofDelimiter(":") .withUpperCase(); byte[] bytes = {(byte) 0xCA, (byte) 0xFE, (byte) 0xBA, (byte) 0xBE}; System.out.println(hex1.formatHex(bytes)); // Output: "CA:FE:BA:BE" // Example 2: Fancy brackets with spaces HexFormat hex2 = HexFormat.ofDelimiter(" ") .withPrefix("[") .withSuffix("]") .withUpperCase(); System.out.println(hex2.formatHex(bytes)); // Output: "[CA] [FE] [BA] [BE]" // Example 3: 0x prefix with space HexFormat hex3 = HexFormat.ofDelimiter(" ") .withPrefix("0x") .withUpperCase(); System.out.println(hex3.formatHex(bytes)); // Output: "0xCA 0xFE 0xBA 0xBE"

🎯 Complete Real-World Examples

📡 Example 1: MAC Address Formatter

import java.util.HexFormat; public class MacAddressFormatter { public static void main(String[] args) { // Create formatter for MAC addresses HexFormat macFormat = HexFormat.ofDelimiter(":") .withUpperCase(); // Example MAC address bytes byte[] macBytes = { (byte) 0x00, (byte) 0x1A, (byte) 0x2B, (byte) 0x3C, (byte) 0x4D, (byte) 0x5E }; // Format to MAC address string String macAddress = macFormat.formatHex(macBytes); System.out.println("MAC Address: " + macAddress); // Output: MAC Address: 00:1A:2B:3C:4D:5E // Parse back to bytes byte[] parsed = macFormat.parseHex("00:1A:2B:3C:4D:5E"); System.out.println("Bytes parsed: " + parsed.length); // Output: Bytes parsed: 6 } }

🔐 Example 2: Hash Display

import java.security.MessageDigest; import java.util.HexFormat; public class HashDisplay { public static void main(String[] args) throws Exception { // Create SHA-256 hash String input = "Hello, Java 17!"; MessageDigest digest = MessageDigest.getInstance("SHA-256"); byte[] hashBytes = digest.digest(input.getBytes()); // Display hash in hex (lowercase) HexFormat hex = HexFormat.of(); String hashHex = hex.formatHex(hashBytes); System.out.println("Input: " + input); System.out.println("SHA-256: " + hashHex); // Output: SHA-256: 3d7a8c... // Also display in uppercase with spaces HexFormat hexDebug = HexFormat.ofDelimiter(" ") .withUpperCase(); System.out.println("Debug: " + hexDebug.formatHex(hashBytes)); // Output: Debug: 3D 7A 8C... } }

🎨 Example 3: RGB Color Converter

import java.util.HexFormat; public class ColorConverter { public static void main(String[] args) { // Create color formatter (#RRGGBB) HexFormat colorFormat = HexFormat.of() .withPrefix("#") .withUpperCase(); // Example: RGB(255, 105, 180) = Hot Pink! byte[] rgb = { (byte) 255, // Red (byte) 105, // Green (byte) 180 // Blue }; // Convert to hex color code String hexColor = colorFormat.formatHex(rgb); System.out.println("Color: " + hexColor); // Output: Color: #FF69B4 // Parse hex color back to RGB String colorCode = "#FF69B4"; byte[] rgbBytes = colorFormat.parseHex(colorCode); System.out.println("RGB: (" + (rgbBytes[0] & 0xFF) + ", " + (rgbBytes[1] & 0xFF) + ", " + (rgbBytes[2] & 0xFF) + ")"); // Output: RGB: (255, 105, 180) } }

📄 Example 4: File Signature Checker

import java.io.*; import java.util.HexFormat; public class FileSignatureChecker { public static void main(String[] args) throws IOException { HexFormat hex = HexFormat.ofDelimiter(" ") .withUpperCase(); // Known file signatures (magic numbers) String pdfSignature = "25 50 44 46"; // %PDF String pngSignature = "89 50 4E 47"; // .PNG String jpgSignature = "FF D8 FF"; // JPEG // Read first 4 bytes of a file byte[] fileHeader = readFileHeader("document.pdf", 4); String headerHex = hex.formatHex(fileHeader); System.out.println("File header: " + headerHex); // Check file type if (headerHex.startsWith(pdfSignature)) { System.out.println("✅ This is a PDF file!"); } else if (headerHex.startsWith(pngSignature)) { System.out.println("✅ This is a PNG file!"); } else if (headerHex.startsWith(jpgSignature)) { System.out.println("✅ This is a JPEG file!"); } else { System.out.println("❓ Unknown file type"); } } static byte[] readFileHeader(String filename, int bytes) throws IOException { try (FileInputStream fis = new FileInputStream(filename)) { byte[] header = new byte[bytes]; fis.read(header); return header; } } }
