🎯 The Problem

Traditional Java requires too much boilerplate for simple programs!

// Traditional Java (verbose!) public class HelloWorld { public static void main(String[] args) { System.out.println("Hello, World!"); } } // 5 lines for one print statement! // Too complex for beginners // Too verbose for scripts

✅ Unnamed Classes

Write simpler programs without explicit class declaration!

// Unnamed class - just write methods! void main() { System.out.println("Hello, World!"); } // That's it! Run with: java HelloWorld.java // Can have instance fields and methods String greeting = "Hello"; int count = 0; void main() { for (int i = 0; i < 3; i++) { printGreeting(); } } void printGreeting() { count++; System.out.println(count + ": " + greeting); }

🚀 Instance Main Methods

main() can now be an instance method without static or String[]!

// Version 1: No parameters void main() { System.out.println("Simple!"); } // Version 2: With args void main(String[] args) { System.out.println("Args: " + Arrays.toString(args)); } // Version 3: Still works (traditional) public static void main(String[] args) { System.out.println("Traditional"); } // Compiler chooses in order: // 1. static void main(String[]) // 2. static void main() // 3. void main(String[]) // 4. void main()

📚 Learning Example

// Complete program - no class needed! int counter = 0; void main() { sayHello(); sayHello(); sayHello(); } void sayHello() { counter++; System.out.println("Hello #" + counter); } // Output: // Hello #1 // Hello #2 // Hello #3 // Perfect for teaching Java basics!

🔧 Scripting Example

// File: process-data.java import java.nio.file.*; import java.util.stream.*; void main(String[] args) { if (args.length == 0) { System.out.println("Usage: process-data.java "); return; } processFile(args[0]); } void processFile(String filename) { try { long count = Files.lines(Path.of(filename)) .filter(line -> !line.isBlank()) .count(); System.out.println("Lines: " + count); } catch (Exception e) { System.err.println("Error: " + e.getMessage()); } } // Run: java process-data.java myfile.txt // No compilation step needed!

💼 Real CLI Tool

// File: json-formatter.java import com.google.gson.*; Gson gson = new GsonBuilder() .setPrettyPrinting() .create(); void main(String[] args) { if (args.length == 0) { System.out.println("Paste JSON, then Ctrl+D:"); String json = readStdin(); formatJson(json); } else { formatFile(args[0]); } } void formatJson(String json) { try { JsonElement element = JsonParser.parseString(json); System.out.println(gson.toJson(element)); } catch (Exception e) { System.err.println("Invalid JSON: " + e.getMessage()); } } void formatFile(String filename) { try { String content = Files.readString(Path.of(filename)); formatJson(content); } catch (Exception e) { System.err.println("Error reading file: " + e.getMessage()); } } String readStdin() { return new Scanner(System.in).useDelimiter("\\Z").next(); }
