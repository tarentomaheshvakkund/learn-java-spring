🎉 The Solution: Three Simplifications!

Progressive Simplification

1

Drop 'public' Modifier

You don't need to say "public" anymore!

// Before: Required "public" public class Hello { public static void main(String[] args) { System.out.println("Hello!"); } } // After: "public" is optional! ✨ class Hello { static void main(String[] args) { // No "public"! System.out.println("Hello!"); } }
2

Drop 'String[] args' Parameter

If you don't need command-line arguments, skip them!

// Before: Always needed args class Hello { static void main(String[] args) { System.out.println("Hello!"); } } // After: Skip args if not needed! ✨ class Hello { static void main() { // No args! System.out.println("Hello!"); } }
3

Drop 'static' - Use Instance Main!

The biggest change - main() can be a normal instance method!

// Before: Always needed "static" class Hello { static void main() { System.out.println("Hello!"); } } // After: "static" is optional! ✨ class Hello { void main() { // No "static"! System.out.println("Hello!"); } }

🚀 The Ultimate Simplification: Unnamed Classes!

📝 Real Life: Quick Note vs Formal Letter

Formal Letter (Traditional Java):

• Just to say "Meeting at 3 PM"!

Quick Note (Unnamed Class):

❌ Named Class (Old)

5 LINES
// File: Hello.java public class Hello { public static void main(String[] args) { System.out.println("Hello!"); } }

✅ Unnamed Class (New)

3 LINES!
// File: Hello.java // No class declaration needed! 🎉 void main() { System.out.println("Hello!"); }

✨ What Happened?

1. No class declaration needed! Java creates an invisible class for you.

2. Just write your main() method! The simplest possible program.

3. Perfect for learning! Focus on logic, not ceremony.

📖 Complete Example: Greeting

// File: Greeter.java // No class declaration! 🎉 // Helper method (yes, you can have these!) String greet(String name) { return "Hello, " + name + "!"; } // Main method void main() { System.out.println(greet("Alice")); // Hello, Alice! System.out.println(greet("Mahesh")); // Hello, Mahesh! } // Run: java --enable-preview --source 21 Greeter.java // Output: // Hello, Alice! // Hello, Mahesh!

🧮 Another Example: Simple Calculator

// File: Calculator.java // Helper methods int add(int a, int b) { return a + b; } int multiply(int a, int b) { return a * b; } // Main method void main() { System.out.println("5 + 3 = " + add(5, 3)); System.out.println("5 × 3 = " + multiply(5, 3)); } // Output: // 5 + 3 = 8 // 5 × 3 = 15
💡 Key Point: You can have helper methods! Unnamed classes aren't limited to just main()!

📊 Full Comparison: All Options

The Evolution of Hello World

Traditional (Pre-Java 21)

5 LINES
public class HelloWorld { public static void main(String[] args) { System.out.println("Hello, World!"); } }

Option 1: Drop 'public'

4 LINES
class HelloWorld { static void main(String[] args) { System.out.println("Hello, World!"); } }

Option 2: Drop 'String[] args'

4 LINES
class HelloWorld { static void main() { System.out.println("Hello, World!"); } }

Option 3: Drop 'static' (Instance Main)

4 LINES
class HelloWorld { void main() { System.out.println("Hello, World!"); } }

Option 4: Unnamed Class (Simplest!)

3 LINES!
// No class declaration needed! void main() { System.out.println("Hello, World!"); }

🚀 How to Run

Step-by-Step Guide

Step 1: Create File

Save your code as Script.java

// Script.java void main() { System.out.println("Hello from unnamed class!"); }

Step 2: Run Directly

No need to compile separately!

# Run with preview features enabled java --enable-preview --source 21 Script.java # Output: # Hello from unnamed class!

⚠️ Remember!

1. Use --enable-preview flag (it's a preview feature)

2. Use --source 21 to specify Java 21

3. Run directly - no need to compile with javac first!

📚 What We Learned

1. Drop 'public': Access modifiers are optional

2. Drop 'String[] args': Skip parameters if not needed

3. Drop 'static': Instance methods work as main()

4. Drop 'class': Unnamed classes let you skip the class declaration entirely!
