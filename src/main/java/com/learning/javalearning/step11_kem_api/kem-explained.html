🤔 What is KEM?

🔒 Real Life: Secret Mailbox

Imagine Alice wants to send Bob a secret message, but they've never met before. How can they agree on a secret password without anyone else knowing?

Old Method (Meeting in person):
• Alice and Bob meet at a coffee shop
• They agree on a secret password face-to-face
• Problem: They have to meet physically! 🤝

KEM Method (Magic Mailbox):
• Bob creates a special mailbox and gives Alice the address (public key)
• Alice puts a secret envelope in Bob's mailbox (encapsulation)
• Bob retrieves the envelope with his special key (decapsulation)
• Both now have the SAME secret, but no one else does! 🎉

This is Key Encapsulation Mechanism! Securely agree on a shared secret without meeting! 🔐

💡 Simple Definition

KEM (Key Encapsulation Mechanism) is a way for two people to agree on a shared secret key without directly exchanging it.

Think of it like: A magic trick where both parties end up with the same secret password, but no one else watching can figure it out!

🎯 The Goal: Alice and Bob need a shared secret key to encrypt messages, but they can't send the key directly (someone might intercept it!). KEM solves this! 🚀

The Technical Flow

1

Bob: Generate Key Pair

Bob creates two keys: one to share (public), one to keep secret (private)

// Bob generates a key pair KeyPairGenerator kpg = KeyPairGenerator.getInstance("X25519"); KeyPair keyPair = kpg.generateKeyPair(); PublicKey publicKey = keyPair.getPublic(); // Share this! PrivateKey privateKey = keyPair.getPrivate(); // Keep secret!
2

Alice: Encapsulate (Create Secret)

Alice uses Bob's public key to create a shared secret and an encapsulation

// Alice encapsulates using Bob's public key KEM kem = KEM.getInstance("DHKEM"); KEM.Encapsulator encapsulator = kem.newEncapsulator(publicKey); // Encapsulate! Creates shared secret + encapsulation KEM.Encapsulated result = encapsulator.encapsulate(); SecretKey sharedSecret = result.key(); // Alice's copy of secret byte[] encapsulation = result.encapsulation(); // Send to Bob
3

Bob: Decapsulate (Retrieve Secret)

Bob uses his private key to extract the same shared secret from the encapsulation

// Bob decapsulates using his private key KEM.Decapsulator decapsulator = kem.newDecapsulator(privateKey); // Decapsulate! Extracts the same secret! SecretKey sameSecret = decapsulator.decapsulate(encapsulation); // Verify they're the same! boolean same = Arrays.equals( sharedSecret.getEncoded(), sameSecret.getEncoded() ); System.out.println("Same secret? " + same); // true! ✅
🔑 The Magic: Alice and Bob now have the SAME secret key, but they never directly sent the key itself! That's the power of KEM! 🎩✨

import javax.crypto.KEM; import javax.crypto.SecretKey; import java.security.*; public class KEMExample { public static void main(String[] args) throws Exception { // ============================================ // STEP 1: Bob generates key pair // ============================================ System.out.println("📦 Bob: Generating key pair..."); KeyPairGenerator kpg = KeyPairGenerator.getInstance("X25519"); KeyPair bobKeyPair = kpg.generateKeyPair(); PublicKey bobPublicKey = bobKeyPair.getPublic(); PrivateKey bobPrivateKey = bobKeyPair.getPrivate(); System.out.println("✅ Bob: Keys generated!"); System.out.println("📢 Bob: Sharing public key with Alice..."); // ============================================ // STEP 2: Alice encapsulates // ============================================ System.out.println("\n👩 Alice: Received Bob's public key"); System.out.println("🎁 Alice: Encapsulating..."); KEM kem = KEM.getInstance("DHKEM"); KEM.Encapsulator encapsulator = kem.newEncapsulator(bobPublicKey); KEM.Encapsulated result = encapsulator.encapsulate(); SecretKey aliceSecret = result.key(); byte[] encapsulation = result.encapsulation(); System.out.println("✅ Alice: Created shared secret!"); System.out.println("📦 Alice: Sending encapsulation to Bob..."); // ============================================ // STEP 3: Bob decapsulates // ============================================ System.out.println("\n👨 Bob: Received encapsulation from Alice"); System.out.println("🔓 Bob: Decapsulating..."); KEM.Decapsulator decapsulator = kem.newDecapsulator(bobPrivateKey); SecretKey bobSecret = decapsulator.decapsulate(encapsulation); System.out.println("✅ Bob: Retrieved shared secret!"); // ============================================ // VERIFY: Do they have the same secret? // ============================================ boolean same = java.util.Arrays.equals( aliceSecret.getEncoded(), bobSecret.getEncoded() ); System.out.println("\n🎉 Result: " + (same ? "SUCCESS!" : "FAILED")); System.out.println("🔐 Both have the same shared secret: " + same); System.out.println("\n💬 Alice and Bob can now encrypt messages to each other!"); } } // Output: // 📦 Bob: Generating key pair... // ✅ Bob: Keys generated! // 📢 Bob: Sharing public key with Alice... // // 👩 Alice: Received Bob's public key // 🎁 Alice: Encapsulating... // ✅ Alice: Created shared secret! // 📦 Alice: Sending encapsulation to Bob... // // 👨 Bob: Received encapsulation from Alice // 🔓 Bob: Decapsulating... // ✅ Bob: Retrieved shared secret! // // 🎉 Result: SUCCESS! // 🔐 Both have the same shared secret: true // 💬 Alice and Bob can now encrypt messages to each other!

🎯 Practical Example: Secure Chat

💬 Building a Secure Chat Application

Here's how you'd use KEM in a real chat app:

import javax.crypto.*; import javax.crypto.spec.GCMParameterSpec; import java.security.*; public class SecureChat { // Step 1: Bob sets up to receive messages public static KeyPair setupReceiver() throws Exception { KeyPairGenerator kpg = KeyPairGenerator.getInstance("X25519"); return kpg.generateKeyPair(); } // Step 2: Alice sends encrypted message to Bob public static EncryptedMessage sendMessage( PublicKey bobPublicKey, String message ) throws Exception { // Use KEM to create shared secret KEM kem = KEM.getInstance("DHKEM"); KEM.Encapsulator enc = kem.newEncapsulator(bobPublicKey); KEM.Encapsulated result = enc.encapsulate(); SecretKey sharedSecret = result.key(); byte[] encapsulation = result.encapsulation(); // Use shared secret to encrypt message with AES Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding"); cipher.init(Cipher.ENCRYPT_MODE, sharedSecret); byte[] ciphertext = cipher.doFinal(message.getBytes()); // Return both encapsulation and encrypted message return new EncryptedMessage(encapsulation, ciphertext, cipher.getIV()); } // Step 3: Bob receives and decrypts message public static String receiveMessage( PrivateKey bobPrivateKey, EncryptedMessage encrypted ) throws Exception { // Use KEM to retrieve shared secret KEM kem = KEM.getInstance("DHKEM"); KEM.Decapsulator dec = kem.newDecapsulator(bobPrivateKey); SecretKey sharedSecret = dec.decapsulate(encrypted.encapsulation); // Use shared secret to decrypt message Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding"); GCMParameterSpec spec = new GCMParameterSpec(128, encrypted.iv); cipher.init(Cipher.DECRYPT_MODE, sharedSecret, spec); byte[] plaintext = cipher.doFinal(encrypted.ciphertext); return new String(plaintext); } // Main: Demo the chat public static void main(String[] args) throws Exception { // Bob sets up KeyPair bobKeys = setupReceiver(); System.out.println("👨 Bob: Ready to receive messages"); // Alice sends message String message = "Hey Bob, let's meet at 3 PM! 🎉"; EncryptedMessage encrypted = sendMessage(bobKeys.getPublic(), message); System.out.println("👩 Alice: Sent encrypted message"); // Bob receives and decrypts String decrypted = receiveMessage(bobKeys.getPrivate(), encrypted); System.out.println("👨 Bob: Received: " + decrypted); } } record EncryptedMessage(byte[] encapsulation, byte[] ciphertext, byte[] iv) {}
