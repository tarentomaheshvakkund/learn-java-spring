🎯 Statement vs Expression

Switch evolved from a statement to an expression that returns values!

❌ Switch Statement (Old)

String result; switch (day) { case MONDAY: case FRIDAY: result = "Work day"; break; case SATURDAY: case SUNDAY: result = "Weekend"; break; default: result = "Unknown"; break; } return result;

✅ Switch Expression (New)

String result = switch (day) { case MONDAY, FRIDAY -> "Work day"; case SATURDAY, SUNDAY -> "Weekend"; default -> "Unknown"; }; return result;

➡️ Arrow Syntax

Use -> to return values directly without break!

// Arrow syntax - no fall-through! int numLetters = switch (day) { case MONDAY, FRIDAY, SUNDAY -> 6; case TUESDAY -> 7; case THURSDAY, SATURDAY -> 8; case WEDNESDAY -> 9; }; // Multiple labels per case String type = switch (month) { case DECEMBER, JANUARY, FEBRUARY -> "Winter"; case MARCH, APRIL, MAY -> "Spring"; case JUNE, JULY, AUGUST -> "Summer"; case SEPTEMBER, OCTOBER, NOVEMBER -> "Fall"; }; // Can be used in return return switch (status) { case 200, 201, 204 -> "Success"; case 400, 404 -> "Client Error"; case 500, 503 -> "Server Error"; default -> "Unknown"; };

🎁 The yield Keyword

Use yield to return values from blocks!

// Simple arrow String result = switch (val) { case 1 -> "one"; case 2 -> "two"; default -> "other"; }; // Block with yield String result = switch (val) { case 1 -> { System.out.println("Processing one"); yield "one"; } case 2 -> { System.out.println("Processing two"); yield "two"; } default -> { String msg = "Unknown: " + val; System.out.println(msg); yield "other"; } }; // Complex logic with yield int price = switch (product) { case "laptop" -> { int basePrice = 1000; int tax = calculateTax(basePrice); int shipping = 50; yield basePrice + tax + shipping; } case "mouse" -> { yield 25; } default -> 0; };

✅ Exhaustiveness Checking

Compiler ensures all cases are covered!

// With enums - no default needed! enum Status { ACTIVE, INACTIVE, PENDING } String message = switch (status) { case ACTIVE -> "Running"; case INACTIVE -> "Stopped"; case PENDING -> "Waiting"; // No default needed! // Compiler knows all cases covered }; // If you add new enum value: // enum Status { ACTIVE, INACTIVE, PENDING, DELETED } // // Compiler ERROR! // "Switch expression must be exhaustive" // // Forces you to handle new case! // With sealed types (Java 17+) sealed interface Result permits Success, Error {} record Success(String data) implements Result {} record Error(String msg) implements Result {} String handle(Result r) { return switch (r) { case Success(var data) -> "OK: " + data; case Error(var msg) -> "Failed: " + msg; // No default needed - exhaustive! }; }

🔢 Calculator Example

class Calculator { double calculate(char operator, double a, double b) { return switch (operator) { case '+' -> a + b; case '-' -> a - b; case '*' -> a * b; case '/' -> { if (b == 0) { throw new ArithmeticException("Divide by zero"); } yield a / b; } case '%' -> a % b; case '^' -> Math.pow(a, b); default -> throw new IllegalArgumentException( "Unknown operator: " + operator ); }; } } // Usage: Calculator calc = new Calculator(); double result = calc.calculate('*', 5, 3); // 15.0

💼 HTTP Status Handler

record Response(int status, String body) {} Response handleResponse(int statusCode, String body) { String message = switch (statusCode) { case 200 -> "OK"; case 201 -> "Created"; case 204 -> "No Content"; case 400 -> "Bad Request"; case 401 -> "Unauthorized"; case 403 -> "Forbidden"; case 404 -> "Not Found"; case 500 -> "Internal Server Error"; case 503 -> "Service Unavailable"; default -> { System.err.println("Unknown status: " + statusCode); yield "Unknown Status"; } }; return new Response(statusCode, message + ": " + body); } // Grouped by category String categorize(int status) { return switch (status) { case 200, 201, 202, 203, 204 -> "Success"; case 300, 301, 302, 303, 304, 307, 308 -> "Redirect"; case 400, 401, 403, 404, 405, 409 -> "Client Error"; case 500, 501, 502, 503, 504 -> "Server Error"; default -> "Unknown"; }; }

🎮 State Machine Example

enum State { IDLE, RUNNING, PAUSED, STOPPED } enum Event { START, PAUSE, RESUME, STOP } State transition(State current, Event event) { return switch (current) { case IDLE -> switch (event) { case START -> State.RUNNING; default -> current; }; case RUNNING -> switch (event) { case PAUSE -> State.PAUSED; case STOP -> State.STOPPED; default -> current; }; case PAUSED -> switch (event) { case RESUME -> State.RUNNING; case STOP -> State.STOPPED; default -> current; }; case STOPPED -> State.STOPPED; }; } // Usage: State state = State.IDLE; state = transition(state, Event.START); // RUNNING state = transition(state, Event.PAUSE); // PAUSED state = transition(state, Event.RESUME); // RUNNING state = transition(state, Event.STOP); // STOPPED

✨ Benefits

  • ✅ Returns values - Use as expression
  • ✅ No break - Cleaner syntax
  • ✅ No fall-through - Safer by default
  • ✅ Multiple labels - case A, B, C
  • ✅ Exhaustiveness - Compiler checks coverage
  • ✅ yield keyword - Complex logic in blocks
  • ✅ Null handling - case null supported
🎯 Use Cases: Configuration mapping, state machines, HTTP handlers, command routers, enum processing
