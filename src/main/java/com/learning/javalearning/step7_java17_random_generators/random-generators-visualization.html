🎯 What's New?

Java 17 introduces a unified RandomGenerator interface with multiple algorithms!

// Old way: Limited options Random random = new Random(); SecureRandom secure = new SecureRandom(); // New way: Many algorithms! RandomGenerator rng = RandomGenerator.of("L64X128MixRandom"); RandomGenerator secure = RandomGenerator.of("L128X1024MixRandom"); // Available algorithms: // - L32X64MixRandom (fast, good quality) // - L64X128MixRandom (better quality) // - L128X1024MixRandom (best quality) // - Xoshiro256PlusPlus (very fast) // - And more...

✨ Benefits

🔧 Creating Random Generators

// Method 1: By algorithm name RandomGenerator rng1 = RandomGenerator.of("L64X128MixRandom"); // Method 2: Default algorithm RandomGenerator rng2 = RandomGenerator.getDefault(); // Method 3: Factory RandomGeneratorFactory factory = RandomGeneratorFactory.of("Xoshiro256PlusPlus"); RandomGenerator rng3 = factory.create(); // Method 4: Get all algorithms RandomGeneratorFactory.all() .map(RandomGeneratorFactory::name) .forEach(System.out::println); // Prints: L32X64MixRandom, L64X128MixRandom, etc.

📊 Common Operations

RandomGenerator rng = RandomGenerator.getDefault(); // Integers int randomInt = rng.nextInt(); // Any int int bounded = rng.nextInt(100); // 0-99 int range = rng.nextInt(10, 20); // 10-19 // Longs long randomLong = rng.nextLong(); long boundedLong = rng.nextLong(1000L); // Doubles double randomDouble = rng.nextDouble(); // 0.0-1.0 double rangeDouble = rng.nextDouble(1.0, 10.0); // Booleans boolean coin = rng.nextBoolean(); // Bytes byte[] bytes = new byte[16]; rng.nextBytes(bytes); // Gaussians double gaussian = rng.nextGaussian(); double gaussianScaled = rng.nextGaussian(100.0, 15.0); // mean, stddev

🌊 Stream Generation

RandomGenerator rng = RandomGenerator.getDefault(); // Stream of random ints rng.ints(10) // 10 random ints .forEach(System.out::println); // Stream with bounds rng.ints(5, 1, 100) // 5 ints between 1-99 .forEach(System.out::println); // Infinite stream (use limit!) rng.doubles() .limit(10) .forEach(System.out::println); // Practical: Random passwords String password = rng.ints(10, 33, 127) .collect(StringBuilder::new, StringBuilder::appendCodePoint, StringBuilder::append) .toString();

💼 Real-World Examples

// Shuffle a list void shuffle(List list, RandomGenerator rng) { for (int i = list.size() - 1; i > 0; i--) { int j = rng.nextInt(i + 1); Collections.swap(list, i, j); } } // Random selection T randomChoice(List list, RandomGenerator rng) { return list.get(rng.nextInt(list.size())); } // Simulation: Monte Carlo Pi estimation double estimatePi(int samples) { RandomGenerator rng = RandomGenerator.getDefault(); long insideCircle = rng.doubles(samples, -1.0, 1.0) .parallel() .mapToObj(x -> { double y = rng.nextDouble(-1.0, 1.0); return x*x + y*y <= 1.0; }) .filter(Boolean::booleanValue) .count(); return 4.0 * insideCircle / samples; }
