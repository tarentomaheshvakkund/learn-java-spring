🎯 Basic Usage

Simple Random Number Generation

// Method 1: Use default generator RandomGenerator random = RandomGenerator.getDefault(); // Generate random int between 0-99 int n = random.nextInt(100); System.out.println("Random number: " + n); // Generate random double between 0.0-1.0 double d = random.nextDouble(); System.out.println("Random double: " + d); // Generate random boolean boolean b = random.nextBoolean(); System.out.println("Random boolean: " + b);

Choosing a Specific Algorithm

// Use a specific high-quality, fast algorithm RandomGenerator xoshiro = RandomGenerator.of("Xoshiro256PlusPlus"); // Generate random numbers int dice = xoshiro.nextInt(1, 7); // 1-6 (dice roll) System.out.println("Dice roll: " + dice); // Generate random number in range int percentage = xoshiro.nextInt(0, 101); // 0-100 System.out.println("Percentage: " + percentage + "%");

🌊 Stream Support: Generate Many at Once!

Old way: Generate one random number at a time (like hand-crafting items one by one)

Stream way: Generate thousands on an assembly line! Much faster and more efficient! 🚀

Example 1: Generate 10 Random Numbers

RandomGenerator random = RandomGenerator.getDefault(); // Generate 10 random ints between 0-100 random.ints(10, 0, 100) .forEach(System.out::println); // Output (example): // 42 // 87 // 15 // 63 // ...

Example 2: Statistics with Streams

RandomGenerator random = RandomGenerator.getDefault(); // Sum of 1000 random doubles (0.0-1.0) double sum = random.doubles(1000, 0, 1).sum(); System.out.println("Sum: " + sum); // Average of 100 random ints (0-100) double avg = random.ints(100, 0, 100) .average() .orElse(0); System.out.println("Average: " + avg); // Find max of 50 random numbers int max = random.ints(50, 0, 100) .max() .orElse(0); System.out.println("Max: " + max);

Example 3: Simulate Dice Rolls

RandomGenerator random = RandomGenerator.getDefault(); // Roll a dice 100 times, count how many 6s long sixes = random.ints(100, 1, 7) // 1-6 .filter(n -> n == 6) .count(); System.out.println("Rolled 6 " + sixes + " times out of 100"); // Generate 20 dice rolls and show them List<Integer> rolls = random.ints(20, 1, 7) .boxed() .toList(); System.out.println("Dice rolls: " + rolls);

⚡ Parallel Processing: Split and Conquer!

👥 Real Life: Team Work

Imagine you need to flip a coin 1 million times:

Single worker: One person flips 1 million times (slow! 🐢)

Team of 4: Split into 4 groups, each flips 250,000 times, then combine! (4x faster! 🚀)

SplittableGenerator does this! Split the random generator for parallel work!

Parallel Random Number Generation

// Create a splittable generator SplittableGenerator gen = (SplittableGenerator) RandomGenerator.of("L64X128MixRandom"); // Split into 4 generators and process in parallel! long sum = gen.splits(4) // Create 4 generators .parallel() // Process in parallel .mapToLong(g -> g.longs(1000).sum() // Each gen sums 1000 longs ) .sum(); // Combine results System.out.println("Total sum: " + sum); // 🚀 4x faster on a 4-core CPU!

Practical Example: Monte Carlo Simulation

// Estimate PI using Monte Carlo method public static double estimatePi(int samples) { SplittableGenerator gen = (SplittableGenerator) RandomGenerator.of("L64X128MixRandom"); // Split work across CPU cores long insideCircle = gen.splits() .parallel() .limit(Runtime.getRuntime().availableProcessors()) .mapToLong(g -> { long count = 0; for (int i = 0; i < samples; i++) { double x = g.nextDouble(); double y = g.nextDouble(); if (x * x + y * y <= 1) count++; } return count; }) .sum(); return 4.0 * insideCircle / samples; } // Run with 10 million samples (very fast!) double pi = estimatePi(10_000_000); System.out.println("Estimated PI: " + pi);
