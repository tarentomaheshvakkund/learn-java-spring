🪆 1. Nested Record Patterns

Destructure nested records in a single expression! Think of it like unpacking nested boxes in one go.

Circle(Point center, int radius)
Point(int x, int y)
x = 5
y = 10
int radius
r = 25
6 lines 😓

❌ Old Way (Java 11-16)

if (shape instanceof Circle) {
    Circle c = (Circle) shape;
    Point center = c.center();
    int x = center.x();
    int y = center.y();
    int r = c.radius();
}
1 line! 🚀

✅ Java 21 Way

if (shape instanceof Circle(Point(int x, int y), int r)) {
    // x, y, r are all available here!
    System.out.println("Center: " + x + "," + y);
    System.out.println("Radius: " + r);
}

🛡️ 2. Guarded Patterns with when

Add boolean conditions to patterns using the when keyword!

Example: Categorizing People by Age

Person(String name, int age) when age < 13 → "Child"
Person(String name, int age) when age < 20 → "Teenager"
Person(String name, int age) when age < 60 → "Adult"
Person(String name, int age) no guard → "Senior"

✅ Complete Code Example

String category = switch (person) {
    case Person(String name, int age) when age < 13  -> name + " is a child";
    case Person(String name, int age) when age < 20  -> name + " is a teenager";
    case Person(String name, int age) when age < 60  -> name + " is an adult";
    case Person(String name, int age)                  -> name + " is a senior";
};

🔇 3. Underscore Pattern _

Use _ when you need to match but don't care about the value!

Pattern Breakdown

Person(
String name
,
int _
)

✅ name is used   |   ❌ age is ignored

❌ Without Underscore

case Person(String n, int unusedAge) -> 
    n + " (age not needed)";

// Warning: 'unusedAge' is never used!

✅ With Underscore

case Person(String n, int _) -> 
    n + " (age explicitly ignored)";

// Clean! No warnings! Intent is clear!

🎨 4. Putting It All Together

Complete Example: Shape Description

String desc = switch (shape) {
    // Destructure Circle with nested Point
    case Circle(Point(int x, int y), int r) ->
        "Circle at (" + x + "," + y + ") radius " + r;

    // Destructure Rectangle with TWO nested Points
    case Rectangle(Point(int x1, int y1), Point(int x2, int y2)) ->
        "Rectangle from (" + x1 + "," + y1 + ") to (" + x2 + "," + y2 + ")";

    // Deep nesting: ColoredShape containing a Circle
    case ColoredShape(String color, Circle(Point(int x, int y), int r)) ->
        color + " circle at (" + x + "," + y + ")";

    default -> "Unknown shape";
};
