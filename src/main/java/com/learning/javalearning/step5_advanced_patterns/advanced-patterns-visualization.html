Guarded Patterns & Nested Record Patterns

Java 21 (Standard)

🛡️ Guarded Patterns (when clause)

Add boolean conditions to patterns for precise matching!

String categorize(Object obj) { return switch (obj) { case String s when s.length() > 10 -> "Long string"; case String s when s.isBlank() -> "Empty string"; case String s -> "Short string: " + s; case Integer i when i > 0 -> "Positive: " + i; case Integer i when i < 0 -> "Negative: " + i; case Integer i -> "Zero"; default -> "Other type"; }; }

✨ Benefits

  • ✅ Combine type check with conditions
  • ✅ More expressive than nested ifs
  • ✅ Guard uses pattern variable
  • ✅ Multiple guards for same type

📦 Nested Record Patterns

Destructure deeply nested records in one pattern!

record Point(int x, int y) {} record Circle(Point center, double radius) {} record Rectangle(Point tl, Point br) {} String describe(Object shape) { return switch (shape) { // Extract nested components! case Circle(Point(var x, var y), var r) -> String.format("Circle at (%d,%d) r=%.1f", x, y, r); case Rectangle( Point(var x1, var y1), Point(var x2, var y2) ) -> String.format("Rectangle [(%d,%d)-(%d,%d)]", x1, y1, x2, y2); case Point(var x, var y) -> "Point(" + x + "," + y + ")"; default -> "Unknown"; }; } // Even deeper nesting! record Address(String city, String zip) {} record Person(String name, Address addr) {} record Company(String name, Person ceo) {} String getCeoCity(Company c) { return switch (c) { case Company( var companyName, Person( var ceoName, Address(var city, var zip) ) ) -> ceoName + " (CEO of " + companyName + ") in " + city; }; }

✨ Power Features

  • ✅ Extract nested values in one step
  • ✅ No manual null checks
  • ✅ Type-safe destructuring
  • ✅ Replaces 20+ lines of code

🔗 Guarded + Nested Patterns

Combine both for maximum expressiveness!

sealed interface Shape {} record Circle(Point center, double radius) implements Shape {} record Rectangle(Point tl, Point br) implements Shape {} String analyzeShape(Shape shape) { return switch (shape) { // Guard on nested component! case Circle(Point(var x, var y), var r) when r > 10 -> "Large circle at " + x + "," + y; case Circle(Point(var x, var y), var r) when x == 0 && y == 0 -> "Circle at origin, r=" + r; case Circle(Point(var x, var y), var r) -> "Small circle at " + x + "," + y; // Guard checking rectangle dimensions case Rectangle( Point(var x1, var y1), Point(var x2, var y2) ) when (x2 - x1) == (y2 - y1) -> "Square from (" + x1 + "," + y1 + ") size=" + (x2-x1); case Rectangle( Point(var x1, var y1), Point(var x2, var y2) ) -> "Rectangle " + (x2-x1) + "x" + (y2-y1); }; }

💼 Real Example: JSON Validation

sealed interface JsonValue {} record JsonString(String value) implements JsonValue {} record JsonNumber(double value) implements JsonValue {} record JsonObject(Map fields) implements JsonValue {} String validate User(JsonValue json) { return switch (json) { case JsonObject(var fields) when fields.containsKey("name") && fields.containsKey("email") && fields.get("name") instanceof JsonString(var name) && fields.get("email") instanceof JsonString(var email) && email.contains("@") -> "Valid user: " + name; case JsonObject(var fields) when !fields.containsKey("name") -> "Error: Missing name field"; case JsonObject(var fields) when !fields.containsKey("email") -> "Error: Missing email field"; default -> "Error: Invalid user format"; }; }
