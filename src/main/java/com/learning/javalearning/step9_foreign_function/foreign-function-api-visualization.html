🎯 What is FFM API?

Replaces JNI (Java Native Interface) with a safer, faster way to call native code and manage off-heap memory.

// Old way: JNI (complex, unsafe!) // - Write C wrapper code // - Use javah to generate headers // - Compile native library // - Load with System.loadLibrary() // - Manual memory management // New way: FFM API (pure Java!) Linker linker = Linker.nativeLinker(); SymbolLookup stdlib = linker.defaultLookup(); // Call C's strlen() function MethodHandle strlen = linker.downcallHandle( stdlib.find("strlen").orElseThrow(), FunctionDescriptor.of(JAVA_LONG, ADDRESS) ); try (Arena arena = Arena.ofConfined()) { MemorySegment str = arena.allocateUtf8String("Hello!"); long length = (long) strlen.invoke(str); System.out.println("Length: " + length); // 6 }

💾 Memory Segments

Safe access to off-heap memory!

// Allocate off-heap memory try (Arena arena = Arena.ofConfined()) { // Allocate 100 bytes MemorySegment segment = arena.allocate(100); // Write data segment.set(ValueLayout.JAVA_INT, 0, 42); segment.set(ValueLayout.JAVA_INT, 4, 99); // Read data int val1 = segment.get(ValueLayout.JAVA_INT, 0); // 42 int val2 = segment.get(ValueLayout.JAVA_INT, 4); // 99 // Automatic cleanup when arena closes! } // Array to native memory try (Arena arena = Arena.ofConfined()) { int[] javaArray = {1, 2, 3, 4, 5}; MemorySegment nativeArray = arena.allocateArray( ValueLayout.JAVA_INT, javaArray ); // Pass nativeArray to native functions }

📞 Calling C Functions

// Call C's printf() function Linker linker = Linker.nativeLinker(); SymbolLookup stdlib = linker.defaultLookup(); MethodHandle printf = linker.downcallHandle( stdlib.find("printf").orElseThrow(), FunctionDescriptor.of(JAVA_INT, ADDRESS), Linker.Option.firstVariadicArg(1) ); try (Arena arena = Arena.ofConfined()) { MemorySegment format = arena.allocateUtf8String("Hello, %s!\\n"); MemorySegment name = arena.allocateUtf8String("World"); printf.invoke(format, name); } // Output: Hello, World! // Call custom library System.load("/path/to/mylib.so"); SymbolLookup myLib = SymbolLookup.loaderLookup(); MethodHandle myFunction = linker.downcallHandle( myLib.find("my_function").orElseThrow(), FunctionDescriptor.of(JAVA_INT, JAVA_INT, JAVA_INT) ); int result = (int) myFunction.invoke(10, 20); // 30

🏗️ Arena Lifecycle

// Confined Arena (try-with-resources) try (Arena arena = Arena.ofConfined()) { MemorySegment seg = arena.allocate(100); // Use seg... } // Automatically freed! // Shared Arena (multiple threads) Arena shared = Arena.ofShared(); MemorySegment seg = shared.allocate(100); // Can be accessed from multiple threads shared.close(); // Must manually close // Auto Arena (garbage collected) Arena auto = Arena.ofAuto(); MemorySegment seg = auto.allocate(100); // No need to close, GC handles it // (but less predictable!)

💼 Real Example: OpenGL Interop

// Load OpenGL library System.load("/usr/lib/libGL.so"); Linker linker = Linker.nativeLinker(); SymbolLookup gl = SymbolLookup.loaderLookup(); // Get glClearColor function MethodHandle glClearColor = linker.downcallHandle( gl.find("glClearColor").orElseThrow(), FunctionDescriptor.ofVoid( JAVA_FLOAT, JAVA_FLOAT, JAVA_FLOAT, JAVA_FLOAT ) ); // Call it! glClearColor.invoke(1.0f, 0.0f, 0.0f, 1.0f); // Red // No JNI boilerplate needed!
