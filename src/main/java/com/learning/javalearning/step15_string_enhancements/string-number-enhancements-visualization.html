📝 String & Number Enhancements

Modern text manipulation & compact formatting in Java 12-13

☕ Java 12 ☕ Java 13

1️⃣ String.indent()

Effortlessly add or remove leading whitespace from each line. Perfect for code generation and text formatting.

String text = "Hello\nWorld"; // Add 4 spaces to each line String indented = text.indent(4); // Result: " Hello\n World\n" // Remove 2 spaces from each line String dedented = text.indent(-2);

❌ Before (Java 11)

String result = Arrays.stream(text.split("\n")) .map(line -> " " + line) .collect(Collectors.joining("\n"));

✅ After (Java 12)

String result = text.indent(4); // Clean, readable, efficient!
💡 Common Use Cases
  • Code Generation: Format generated Java/SQL/JSON with proper indentation
  • Template Processing: Adjust text block indentation dynamically
  • Logging & Reports: Create hierarchical log messages
  • Remove Indentation: Use negative values like text.indent(-4)

2️⃣ String.transform()

Apply a function to a string in a fluent, chainable way. Makes complex transformations readable and elegant.

String result = " hello world " .transform(String::trim) .transform(String::toUpperCase) .transform(s -> s.replace(" ", "-")); // Result: "HELLO-WORLD"

❌ Nested Approach

String result = someMethod( anotherMethod( yetAnotherMethod(text) ) ); // Hard to read!

✅ Fluent Chain

String result = text .transform(this::someMethod) .transform(this::anotherMethod) .transform(this::yetAnotherMethod); // Clean pipeline!
✨ Real-World Examples
  • URL Slugs: Convert "Hello World!" to "hello-world"
  • Phone Formatting: Transform "1234567890" to "(123) 456-7890"
  • Data Sanitization: Chain trim, lowercase, and validation
  • Custom Pipelines: Build reusable transformation chains

3️⃣ String.stripIndent()

Remove incidental whitespace from text blocks while preserving intentional formatting. Essential for multi-line strings.

String html = """ <div> <h1>Title</h1> <p>Content</p> </div> """.stripIndent(); // Removes common leading whitespace // Preserves relative indentation
💡 Perfect For
  • SQL Queries: Clean formatting without extra spaces
  • JSON/XML Templates: Remove indentation from text blocks
  • Email Templates: Format multi-line messages
  • Documentation: Embedded code examples in strings

4️⃣ String.translateEscapes()

Process escape sequences like \n, \t, \r in strings. Useful when reading escape sequences from external sources.

String raw = "Hello\\nWorld\\t!"; String processed = raw.translateEscapes(); // Result: "Hello\nWorld\t!" // Actual newline and tab characters

❌ Manual Processing

String result = text .replace("\\n", "\n") .replace("\\t", "\t") .replace("\\r", "\r") .replace("\\\\", "\\"); // Error-prone!

✅ Built-in Method

String result = text.translateEscapes(); // Handles all escapes correctly
⚠️ Important Notes
  • Processes standard Java escape sequences: \n, \t, \r, \\, \", \'
  • Use when reading escaped strings from files/databases
  • Don't use on already-escaped Java string literals (redundant)
  • Throws exception for invalid escape sequences

5️⃣ Compact Number Formatting

Format large numbers in a human-readable way: 1,000 → "1K", 1,000,000 → "1M". Perfect for dashboards and social media displays.

NumberFormat fmt = NumberFormat .getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT); System.out.println(fmt.format(1000)); // "1K" System.out.println(fmt.format(1000000)); // "1M" System.out.println(fmt.format(1000000000)); // "1B"

📊 SHORT vs LONG Styles

Number SHORT Style LONG Style
1,000 1K 1 thousand
1,000,000 1M 1 million
1,000,000,000 1B 1 billion
1,500,000 2M 2 million
✨ Real-World Applications
  • Social Media: "1.2K likes", "5M followers", "234K views"
  • Analytics Dashboards: Display metrics compactly
  • File Sizes: "2.5M" instead of "2,500,000 bytes"
  • Financial Reports: "$1.2M revenue", "$500K profit"

7️⃣ Practical Examples

See how these features work together in real applications.

📱 Social Media Counter

public class SocialMediaCounter { private static final NumberFormat formatter = NumberFormat.getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT); public static String formatCount(long count) { return formatter.format(count); } } // Usage formatCount(1234) // "1K" formatCount(987654) // "988K" formatCount(5_000_000) // "5M"

🔧 Advanced String Processing

String processTemplate(String template, Map<String, String> vars) { return template .stripIndent() .translateEscapes() .transform(s -> replaceVariables(s, vars)) .transform(String::trim); } // Chain multiple transformations elegantly!
💡 Best Practices
  • Reuse Formatters: NumberFormat instances are expensive, cache them
  • Chain Wisely: Order transform() calls for maximum efficiency
  • Test Locales: Always test with target locales, formats vary
  • Null Safety: Handle null checks before transformations

8️⃣ Parsing Compact Numbers

Convert compact number strings back to numeric values.

NumberFormat fmt = NumberFormat .getCompactNumberInstance(Locale.US, NumberFormat.Style.SHORT); // Parse compact notation back to numbers Number parsed = fmt.parse("1.2K"); // 1200 Number parsed = fmt.parse("5M"); // 5000000 Number parsed = fmt.parse("3.5B"); // 3500000000
⚠️ Parsing Considerations
  • parse() returns Number, cast to Long/Double as needed
  • Can throw ParseException for invalid formats
  • Locale-specific parsing: "1.5K" works in US, "1,5K" in Germany
  • Always use same locale for formatting and parsing
