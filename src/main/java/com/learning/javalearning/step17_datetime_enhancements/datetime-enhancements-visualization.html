🕐 Day Period Support ('B' Pattern)

Java 16 introduced the 'B' pattern for natural day period descriptions. Instead of "AM/PM", display "in the morning", "in the afternoon", etc.

🌙 Night
00:00-05:59
🌅 Morning
06:00-11:59
☀️ Afternoon
12:00-17:59
🌆 Evening
18:00-23:59
❌ OLD WAY (AM/PM) 
DateTimeFormatter fmt = DateTimeFormatter
    .ofPattern("h:mm a");

// Output: "3:30 PM"
//         "9:00 AM"
//         "12:00 PM"
✅ NEW WAY (Day Period) 
DateTimeFormatter fmt = DateTimeFormatter
    .ofPattern("h:mm B");

// Output: "3:30 in the afternoon"
//         "9:00 in the morning"
//         "12:00 noon"

🔤 Day Period Pattern Variations

Pattern Type 3:30 PM 9:00 AM 12:00 PM
h:mm a AM/PM 3:30 PM 9:00 AM 12:00 PM
h:mm B Abbreviated 3:30 in the afternoon 9:00 in the morning 12:00 noon
h:mm BBBB Wide 3:30 in the afternoon 9:00 in the morning 12:00 noon
h:mm BBBBB Narrow 3:30 in the afternoon 9:00 in the morning 12:00 noon

🔧 Advanced DateTimeFormatterBuilder

Custom Builder

DateTimeFormatter custom = new DateTimeFormatterBuilder()
    .appendText(ChronoField.DAY_OF_WEEK, TextStyle.FULL)
    .appendLiteral(", ")
    .appendText(ChronoField.MONTH_OF_YEAR, TextStyle.FULL)
    .appendLiteral(" ")
    .appendValue(ChronoField.DAY_OF_MONTH)
    .appendLiteral(" at ")
    .appendValue(ChronoField.HOUR_OF_AMPM)
    .appendLiteral(":")
    .appendValue(ChronoField.MINUTE_OF_HOUR, 2)
    .toFormatter(Locale.US);

// "Tuesday, February 24 at 3:30"

Optional Sections

DateTimeFormatter flexible = new DateTimeFormatterBuilder()
    .appendPattern("yyyy-MM-dd HH:mm:ss")
    .optionalStart()
    .appendLiteral(" [")
    .appendZoneId()
    .appendLiteral("]")
    .optionalEnd()
    .toFormatter();

// "2026-02-24 15:30:00"
// "2026-02-24 15:30:00 [America/New_York]"

Case-Insensitive Parsing

DateTimeFormatter parser = new DateTimeFormatterBuilder()
    .parseCaseInsensitive()
    .appendPattern("yyyy-MMM-dd")
    .toFormatter(Locale.US);

// Parses: "2026-FEB-24", "2026-feb-24", "2026-Feb-24"

📅 Temporal Adjusters & Date Streams

Temporal Adjusters

LocalDate today = LocalDate.of(2026, 2, 24);

// Built-in adjusters
today.with(TemporalAdjusters.firstDayOfMonth());
today.with(TemporalAdjusters.lastDayOfMonth());
today.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
today.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));

// Custom: next business day
today.with(d -> {
    LocalDate next = LocalDate.from(d).plusDays(1);
    while (isWeekend(next)) next = next.plusDays(1);
    return next;
});

Date Streams (Java 9+)

LocalDate start = LocalDate.of(2026, 2, 24);
LocalDate end = LocalDate.of(2026, 3, 3);

// All dates in range
start.datesUntil(end).toList();

// Every 3 days
start.datesUntil(end, Period.ofDays(3)).toList();

// Business days only
start.datesUntil(end)
    .filter(d -> d.getDayOfWeek().getValue() < 6)
    .toList();

✅ Best Practices

Do

  • Use 'B' for user-facing time displays
  • Always specify a Locale with formatters
  • Cache DateTimeFormatter instances (thread-safe)
  • Use DateTimeFormatterBuilder for complex patterns
  • Use datesUntil() for date range generation
  • Handle time zones explicitly

Don't

  • ✗ Use AM/PM for i18n user-facing displays
  • ✗ Assume system default time zone
  • ✗ Create new formatter per format call
  • ✗ Use java.util.Date for new code
  • ✗ Mix old and new date/time APIs
  • ✗ Ignore locale in formatting
