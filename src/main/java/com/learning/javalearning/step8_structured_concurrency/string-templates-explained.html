📝 String Templates

The Easiest Way to Build Strings in Java!

⚠️ Preview Feature - Use --enable-preview

😰 The Old Problem: Building Strings is PAINFUL!

💬 Real Life: Sending a WhatsApp Message

Imagine you want to send a message to your friend:
"Hey Mahesh, your order #12345 of ₹2500 will arrive tomorrow!"

In old Java, you had to painfully piece this together using:
• Method 1: Concatenation with + (messy!)
• Method 2: String.format() (confusing placeholders!)
• Method 3: StringBuilder (too verbose!)

❌ The Three Old (Painful) Ways

1️⃣ Concatenation

String name = "Mahesh"; int orderId = 12345; int amount = 2500; String msg = "Hey " + name + ", your order #" + orderId + " of ₹" + amount + " will arrive tomorrow!"; // 😱 So many + signs! // Easy to forget spaces!
😫😫😫 Pain Level: HIGH

2️⃣ String.format()

String name = "Mahesh"; int orderId = 12345; int amount = 2500; String msg = String.format( "Hey %s, your order #%d of ₹%d will arrive tomorrow!", name, orderId, amount ); // 🤔 What's %s? What's %d? // Hard to read! // Order of variables matters!
😕😕 Pain Level: MEDIUM

3️⃣ String Template ✨

String name = "Mahesh"; int orderId = 12345; int amount = 2500; String msg = STR."Hey \{name}, your order #\{orderId} of ₹\{amount} will arrive tomorrow!"; // 😍 SO CLEAN! // Variables right where you need them! // Easy to read and understand!
😊😊😊 Pain Level: ZERO!
💡 Key Point: String Templates put variables EXACTLY where they appear in the text! No more counting placeholders or adding + signs!

🔧 How String Templates Work

Visual Flow:

name = "Mahesh"
age = 25
→
STR."Hello, \{name}!
You are \{age} years old."
→
"Hello, Mahesh!
You are 25 years old."
Magic Happening: Java replaces \{name} with "Mahesh" and \{age} with 25!

📖 The Syntax

Format: STR."Your text \{variable} more text"

Breaking it down:
• STR = The String Template Processor (does the magic!)
• . = Connects STR to your template
• "..." = Your string with placeholders
• \{variable} = Insert variable value here!

🧮 You Can Use Expressions Too!

🎂 Real Life: Birthday Reminder

You want to tell someone their age next year. Instead of calculating separately, you can do the math RIGHT INSIDE the template!

Example 1: Math Inside Templates

int age = 25; // You can do calculations inside \{} ! String msg1 = STR."You are \{age} years old"; String msg2 = STR."Next year you'll be \{age + 1}"; String msg3 = STR."10 years ago you were \{age - 10}"; // Output: // You are 25 years old // Next year you'll be 26 // 10 years ago you were 15

Example 2: Method Calls Inside Templates

String name = "mahesh"; // Call methods directly inside \{} ! String greeting = STR."Hello, \{name.toUpperCase()}!"; // Output: Hello, MAHESH! int price = 1250; String bill = STR."Total: ₹\{String.format("%.2f", price / 100.0)}"; // Output: Total: ₹12.50

Example 3: Conditions Inside Templates

int age = 17; // Use ternary operator for conditions! String status = STR."You are \{age >= 18 ? "an adult" : "a minor"}"; // Output: You are a minor boolean isWeekend = true; String plan = STR."Today is \{isWeekend ? "party time!" : "work day"}"; // Output: Today is party time!
💡 Power Move: You can put ANY Java expression inside \{ }! Math, method calls, conditions - anything!

📄 Multi-Line Templates (Text Blocks)

📧 Real Life: Sending an Email

You need to send a professional email with multiple lines. String Templates work PERFECTLY with text blocks (those triple quotes """)!

❌ Old Way (Painful!)

String name = "Mahesh"; int orderId = 12345; String email = "Dear " + name + ",\n" + "\n" + "Your order #" + orderId + " has been confirmed.\n" + "Expected delivery: Tomorrow\n" + "\n" + "Thank you for shopping with us!\n" + "\n" + "Best regards,\n" + "The Team"; // 😱 All those + and \n !

✅ New Way (Beautiful!)

String name = "Mahesh"; int orderId = 12345; String email = STR.""" Dear \{name}, Your order #\{orderId} has been confirmed. Expected delivery: Tomorrow Thank you for shopping with us! Best regards, The Team """; // 😍 Clean and readable! // Looks exactly like the email!

🎯 Real Example: JSON Generation

Scenario: You need to create JSON for an API request
String name = "Mahesh"; int age = 25; String city = "Mumbai"; boolean isActive = true; // Generate JSON easily! String json = STR.""" { "name": "\{name}", "age": \{age}, "city": "\{city}", "active": \{isActive}, "adult": \{age >= 18} } """; // Output: // { // "name": "Mahesh", // "age": 25, // "city": "Mumbai", // "active": true, // "adult": true // }

🎯 Another Example: HTML Generation

String title = "Welcome"; String username = "Mahesh"; int notifications = 5; String html = STR.""" <html> <head> <title>\{title}</title> </head> <body> <h1>Hello, \{username}!</h1> <p>You have \{notifications} new notifications.</p> </body> </html> """; // Perfect for generating HTML dynamically!

🌍 Comparison with Other Languages

💡 Good News!

If you know JavaScript or Python, you already understand String Templates! Java finally has the same clean syntax!

Language Syntax Example
JavaScript `${variable}` `Hello, ${name}!`
Python f"{variable}" f"Hello, {name}!"
Java 21 STR."\{variable}" STR."Hello, \{name}!"

🚀 How to Use String Templates

⚠️ Important: Preview Feature!

String Templates are a PREVIEW feature in Java 21. This means you need to enable it with a special flag!

Step 1: Compile Your Code

# Add --enable-preview flag javac --enable-preview --source 21 YourFile.java

Step 2: Run Your Code

# Also use --enable-preview when running java --enable-preview YourFile

Complete Example File

// StringTemplateExample.java public class StringTemplateExample { public static void main(String[] args) { String name = "Mahesh"; int age = 25; // Use String Template! String message = STR."Hello, \{name}! You are \{age} years old."; System.out.println(message); // Output: Hello, Mahesh! You are 25 years old. } } // Compile: // javac --enable-preview --source 21 StringTemplateExample.java // Run: // java --enable-preview StringTemplateExample

🎯 Quick Summary

✨ What Are String Templates?

A clean way to insert variables and expressions directly into strings - no more messy concatenation or confusing placeholders!

📝 The Syntax

STR."text \{variable} more text"

💪 What You Can Put Inside \{ }

• Variables: \{name}
• Math: \{age + 1}
• Methods: \{name.toUpperCase()}
• Conditions: \{age >= 18 ? "adult" : "minor"}
• ANY Java expression!

⚠️ Remember

• Preview feature - use --enable-preview
• Works with text blocks (multi-line)
• Similar to JavaScript template literals and Python f-strings

Bottom Line: String Templates make Java strings as easy as JavaScript and Python! 🎉
