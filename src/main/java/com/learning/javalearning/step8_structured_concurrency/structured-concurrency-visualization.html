🎯 What is Structured Concurrency?

A programming paradigm where concurrent tasks have a clear parent-child relationship and lifecycle management.

// Problem with unstructured concurrency ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor(); Future f1 = executor.submit(() -> fetchUser()); Future f2 = executor.submit(() -> fetchOrders()); // What if one fails? Other keeps running! // What if parent exits early? Tasks become orphaned! // Solution: Structured Concurrency try (var scope = new StructuredTaskScope.ShutdownOnFailure()) { Future user = scope.fork(() -> fetchUser()); Future orders = scope.fork(() -> fetchOrders()); scope.join(); // Wait for all scope.throwIfFailed(); // Propagate errors return new UserData(user.resultNow(), orders.resultNow()); } // Tasks are cancelled if scope closes early! // No orphaned threads!

🛑 ShutdownOnFailure

Cancel all tasks if any one fails!

record UserProfile(String name, List orders, List preferences) {} UserProfile fetchUserProfile(int userId) throws Exception { try (var scope = new StructuredTaskScope.ShutdownOnFailure()) { // Launch 3 concurrent tasks var userFuture = scope.fork(() -> fetchUserData(userId)); var ordersFuture = scope.fork(() -> fetchUserOrders(userId)); var prefsFuture = scope.fork(() -> fetchPreferences(userId)); // Wait for all or fail fast scope.join(); scope.throwIfFailed(); // If any failed, throw! // All succeeded - get results return new UserProfile( userFuture.resultNow(), ordersFuture.resultNow(), prefsFuture.resultNow() ); } // If scope exits (exception/return), all tasks cancelled! }

🏆 ShutdownOnSuccess

Return as soon as first task succeeds!

// Race multiple servers, use fastest response String fetchFromFastestServer(List servers) throws Exception { try (var scope = new StructuredTaskScope.ShutdownOnSuccess()) { // Query all servers concurrently for (String server : servers) { scope.fork(() -> fetchFromServer(server)); } // Wait for first success scope.join(); // Return first successful result return scope.result(); } // Other tasks automatically cancelled! } // Find first matching item T findFirst(List> tasks, Predicate condition) throws Exception { try (var scope = new StructuredTaskScope.ShutdownOnSuccess()) { for (var task : tasks) { scope.fork(() -> { T result = task.call(); if (condition.test(result)) { return result; } throw new NoSuchElementException(); }); } scope.join(); return scope.result(); } }

🔄 Scoped Values

Better alternative to ThreadLocal for virtual threads!

// Problem with ThreadLocal class UserContext { private static final ThreadLocal current = new ThreadLocal<>(); // With 1M virtual threads, this creates 1M User objects! } // Solution: Scoped Values class UserContext { static final ScopedValue CURRENT = ScopedValue.newInstance(); } // Usage: User user = authenticate(request); // Run code with user context ScopedValue.where(UserContext.CURRENT, user) .run(() -> { // Inside this scope, UserContext.CURRENT.get() returns user processRequest(); // Can nest scopes! Transaction tx = beginTransaction(); ScopedValue.where(TransactionContext.CURRENT, tx) .run(() -> { // Both user and tx accessible here saveToDatabase(); }); }); // Outside scope, UserContext.CURRENT.get() throws
Benefits: Immutable, efficient for virtual threads, clear lifetime

💼 Real-World: API Aggregation

record Dashboard( String userData, List recentOrders, Map analytics, List notifications ) {} Dashboard loadDashboard(int userId) throws Exception { try (var scope = new StructuredTaskScope.ShutdownOnFailure()) { // Launch 4 API calls concurrently var userTask = scope.fork( () -> userService.getUser(userId) ); var ordersTask = scope.fork( () -> orderService.getRecentOrders(userId) ); var analyticsTask = scope.fork( () -> analyticsService.getStats(userId) ); var notifTask = scope.fork( () -> notificationService.getUnread(userId) ); // Wait for all (max 5 seconds) scope.join(); scope.throwIfFailed(); // Construct dashboard from results return new Dashboard( userTask.resultNow(), ordersTask.resultNow(), analyticsTask.resultNow(), notifTask.resultNow() ); } // If any API call fails or times out, // all other calls are cancelled immediately! }
