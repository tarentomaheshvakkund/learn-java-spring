🌐 HTTP Client API

Standardized HTTP client replacing legacy HttpURLConnection

// Create HTTP client HttpClient client = HttpClient.newBuilder() .version(HttpClient.Version.HTTP_2) .followRedirects(HttpClient.Redirect.NORMAL) .connectTimeout(Duration.ofSeconds(20)) .build(); // Synchronous GET request HttpRequest request = HttpRequest.newBuilder() .uri(URI.create("https://api.example.com/users")) .timeout(Duration.ofMinutes(2)) .header("Content-Type", "application/json") .GET() .build(); HttpResponse response = client.send(request, HttpResponse.BodyHandlers.ofString()); // Asynchronous request client.sendAsync(request, HttpResponse.BodyHandlers.ofString()) .thenApply(HttpResponse::body) .thenAccept(System.out::println) .join();

🔤 String Methods

New utility methods for string manipulation

// isBlank() - checks if empty or only whitespace " ".isBlank(); // true " text ".isBlank(); // false // strip() - removes leading/trailing whitespace (Unicode-aware) " Hello ".strip(); // "Hello" " Hello ".stripLeading(); // "Hello " " Hello ".stripTrailing(); // " Hello" // repeat() - repeats string n times "Java ".repeat(3); // "Java Java Java " // lines() - returns stream of lines String text = "Line1\nLine2\nLine3"; text.lines().forEach(System.out::println); // Performance comparison vs trim() // strip() handles Unicode whitespace properly String unicode = "\u2005Hello\u2005"; unicode.trim(); // "\u2005Hello\u2005" (unchanged) unicode.strip(); // "Hello" (correct!)

🗂️ Files Methods

Simplified file operations

// Read file as string Path path = Path.of("data.txt"); String content = Files.readString(path); // Write string to file Files.writeString(path, "Hello World", StandardOpenOption.CREATE); // isSameFile() - compares paths Path p1 = Path.of("file.txt"); Path p2 = Path.of("./file.txt"); Files.isSameFile(p1, p2); // true // Example: Read, transform, write String data = Files.readString(Path.of("input.txt")); String upper = data.toUpperCase(); Files.writeString(Path.of("output.txt"), upper);

🎯 Local-Variable var in Lambda

Use var in lambda parameters for annotations

// Before Java 11 - can't annotate BiFunction add = (a, b) -> a + b; // Java 11 - can use annotations with var BiFunction add = (@Nonnull var a, @Nonnull var b) -> a + b; // Useful for custom annotations list.stream() .map((@Lowercase var s) -> s.toLowerCase()) .collect(Collectors.toList()); // Mix var with type inference var list = List.of(1, 2, 3); list.forEach((var item) -> System.out.println(item));

🚫 Not Collection.toArray()

// Easy array creation from collections List list = List.of("A", "B", "C"); // Old way - required generator function String[] oldWay = list.toArray(String[]::new); // Java 11 way - simpler! String[] array = list.toArray(String[]::new); // For primitive arrays, still use streams int[] ints = list.stream() .mapToInt(Integer::parseInt) .toArray();

🔄 Optional.isEmpty()

// Check if Optional is empty Optional opt = Optional.empty(); // Before Java 11 if (!opt.isPresent()) { // handle empty } // Java 11+ if (opt.isEmpty()) { // handle empty - more intuitive! } // Example usage Optional user = findUser(id); if (user.isEmpty()) { throw new UserNotFoundException(id); } return user.get();

🔢 Predicate.not()

// Negate predicates easily List names = List.of("Alice", "", "Bob", " ", "Charlie"); // Before Java 11 names.stream() .filter(s -> !s.isBlank()) .collect(Collectors.toList()); // Java 11+ with predicate negation names.stream() .filter(Predicate.not(String::isBlank)) .collect(Collectors.toList()); // More examples users.stream() .filter(Predicate.not(User::isDeleted)) .filter(Predicate.not(User::isSuspended)) .collect(Collectors.toList());
