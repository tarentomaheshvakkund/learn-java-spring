🔍 Pattern Matching for Switch

Type Patterns, Guarded Patterns & Record Patterns

Java 21 (Standard) Preview: Java 17-20

🎯 Type Pattern Matching

Match and extract types in one step - no more instanceof + cast!

❌ Old Way (Verbose)

String format(Object obj) { String result; if (obj instanceof Integer) { Integer i = (Integer) obj; result = "int: " + i; } else if (obj instanceof String) { String s = (String) obj; result = "String: " + s; } else if (obj instanceof Long) { Long l = (Long) obj; result = "long: " + l; } else { result = "Unknown"; } return result; }

✅ Pattern Matching (Clean)

String format(Object obj) { return switch (obj) { case Integer i -> "int: " + i; case String s -> "String: " + s; case Long l -> "long: " + l; case null -> "null value"; default -> "Unknown"; }; }

✨ Benefits

  • ✅ No manual casting needed
  • ✅ Type and extract in one step
  • ✅ Null-safe by default
  • ✅ More readable and maintainable

🛡️ Guarded Patterns (when)

Add conditions to patterns for even more precise matching!

String categorize(Object obj) { return switch (obj) { case String s when s.length() > 10 -> "Long string: " + s.substring(0, 10) + "..."; case String s when s.isBlank() -> "Empty or blank string"; case String s -> "Short string: " + s; case Integer i when i > 0 -> "Positive number: " + i; case Integer i when i < 0 -> "Negative number: " + i; case Integer i -> "Zero"; case null -> "Null value"; default -> "Other type"; }; } // Real-world example: HTTP status codes String handleResponse(int statusCode) { return switch (statusCode) { case int s when s >= 200 && s < 300 -> "Success!"; case int s when s >= 300 && s < 400 -> "Redirect"; case int s when s >= 400 && s < 500 -> "Client error"; case int s when s >= 500 -> "Server error"; default -> "Unknown status"; }; }

✨ Power of Guards

  • ✅ Combine type checking with conditions
  • ✅ More expressive than nested ifs
  • ✅ Guard expressions can use matched variable
  • ✅ Multiple guards for same type

📦 Record Pattern Matching

Destructure records directly in pattern matching - extract components in one step!

record Point(int x, int y) {} record Circle(Point center, double radius) {} record Rectangle(Point topLeft, Point bottomRight) {} // Destructure records in switch! String describe(Object shape) { return switch (shape) { case Circle(Point(var x, var y), var r) -> "Circle at (" + x + "," + y + ") with radius " + r; case Rectangle( Point(var x1, var y1), Point(var x2, var y2) ) -> "Rectangle from (" + x1 + "," + y1 + ") to (" + x2 + "," + y2 + ")"; case Point(var x, var y) -> "Point at (" + x + "," + y + ")"; case null -> "No shape"; default -> "Unknown shape"; }; } // Usage: Circle c = new Circle(new Point(0, 0), 5.0); System.out.println(describe(c)); // Output: Circle at (0,0) with radius 5.0
🎯 Key Insight: Record patterns let you "unwrap" nested data structures in a single pattern, making code dramatically more concise!

🎁 Deeply Nested Patterns

Handle complex nested structures with ease!

record Address(String street, String city, String zip) {} record Person(String name, int age, Address address) {} record Company(String name, Person ceo) {} // Deep nesting extraction! String getCeoCity(Object obj) { return switch (obj) { // Extract city 3 levels deep! case Company( var companyName, Person( var ceoName, var age, Address(var street, var city, var zip) ) ) -> ceoName + " (CEO of " + companyName + ") lives in " + city; case Person( var name, var age, Address(var street, var city, var zip) ) -> name + " lives in " + city; case Address(var street, var city, var zip) -> "Address in " + city; case null -> "No data"; default -> "Invalid type"; }; } // Before pattern matching, this would require: // - Multiple instanceof checks // - Multiple casts // - Null checks at each level // - 20+ lines of boilerplate!

✅ Exhaustiveness Checking

Compiler ensures you handle all possible cases!

sealed interface Result permits Success, Error {} record Success(String data) implements Result {} record Error(String message) implements Result {} // No default needed - exhaustive! String handle(Result result) { return switch (result) { case Success(var data) -> "Got: " + data; case Error(var msg) -> "Failed: " + msg; // Compiler knows all cases covered! }; } // If you add a new type: // record Pending() implements Result {} // // The compiler will give ERROR: // "The switch expression does not cover // all possible input values" // // This prevents bugs at COMPILE TIME!

✨ Exhaustiveness Benefits

  • ✅ Catch missing cases at compile time
  • ✅ Safe refactoring when adding new types
  • ✅ No runtime surprises
  • ✅ Works with sealed types

💼 Real-World Example

JSON parser with pattern matching

sealed interface JsonValue {} record JsonString(String value) implements JsonValue {} record JsonNumber(double value) implements JsonValue {} record JsonBoolean(boolean value) implements JsonValue {} record JsonNull() implements JsonValue {} record JsonArray(List<JsonValue> items) implements JsonValue {} record JsonObject(Map<String, JsonValue> fields) implements JsonValue {} // Convert to Java types with pattern matching Object toJava(JsonValue json) { return switch (json) { case JsonString(var s) -> s; case JsonNumber(var n) -> n; case JsonBoolean(var b) -> b; case JsonNull() -> null; case JsonArray(var items) -> items.stream() .map(this::toJava) .toList(); case JsonObject(var fields) -> fields.entrySet().stream() .collect(Collectors.toMap( Map.Entry::getKey, e -> toJava(e.getValue()) )); }; } // Pretty printing with guards String prettyPrint(JsonValue json, int indent) { return switch (json) { case JsonString(var s) -> "\"" + s + "\""; case JsonNumber(var n) when n % 1 == 0 -> String.valueOf((int) n); case JsonNumber(var n) -> String.valueOf(n); case JsonBoolean(var b) -> String.valueOf(b); case JsonNull() -> "null"; case JsonArray(var items) when items.isEmpty() -> "[]"; case JsonArray(var items) -> "[\n" + items.stream() .map(v -> " ".repeat(indent + 2) + prettyPrint(v, indent + 2)) .collect(Collectors.joining(",\n")) + "\n" + " ".repeat(indent) + "]"; case JsonObject(var fields) when fields.isEmpty() -> "{}"; case JsonObject(var fields) -> "{\n" + fields.entrySet().stream() .map(e -> " ".repeat(indent + 2) + "\"" + e.getKey() + "\": " + prettyPrint(e.getValue(), indent + 2)) .collect(Collectors.joining(",\n")) + "\n" + " ".repeat(indent) + "}"; }; }

🔄 Pattern Matching Flow

1
Type Test
Check if value matches the pattern type (e.g., Integer, String)
2
Guard Evaluation (Optional)
If 'when' clause exists, evaluate the condition
3
Binding
If match succeeds, bind the value to pattern variable(s)
4
Deconstruction (Records)
For record patterns, extract component values automatically
5
Execute Branch
Run the code for the matched case with bound variables
